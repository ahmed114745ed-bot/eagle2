# نظام تخصيص العناصر الفرعية
## Child Customizer System - دليل المستخدم الشامل

---

## 🎯 مقدمة عن النظام

نظام تخصيص العناصر الفرعية يسمح لك برسم وتحرير شكل وألوان العناصر الفرعية داخل الويدجتات مباشرة من لوحة التحكم.

**الهدف الرئيسي:** تمكين المستخدمين من تخصيص كامل تصميم العناصر الفرعية بدون الحاجة لكود.

---

## ✨ الميزات الرئيسية

### 1️⃣ رسم الأشكال
```
✓ اختيار شكل العنصر
✓ تقوس الزوايا قابل للتحكم
✓ تحديد الأبعاد (العرض والارتفاع)
✓ وضع العنصر (موضعه على الشاشة)
```

### 2️⃣ تحديد الألوان
```
✓ لون الخلفية
✓ لون النص
✓ لون الحدود
✓ اختيار من Presets سابقة
✓ لون مخصص بـ Color Picker
```

### 3️⃣ إضافة الحدود والظلال
```
✓ حدود بسمك وألوان مختلفة
✓ أنواع حدود (صلب، متقطع، نقاط)
✓ ظلال متقدمة (إزاحة، ضبابية، شفافية)
✓ تأثيرات بصرية
```

### 4️⃣ الحركات والتأثيرات
```
✓ حركات دخول (Fade, Slide, Bounce)
✓ نبضات مستمرة (Pulse)
✓ تحكم سرعة الحركة
✓ تأخير الحركة
```

### 5️⃣ المعاينة الحية
```
✓ رؤية التغييرات فوراً
✓ عرض كود CSS المولد
✓ معاينة على أحجام مختلفة
✓ نسخ الكود بضغطة زر
```

## 🚀 كيفية الاستخدام

### الخطوة 1: الوصول إلى محرر العناصر الفرعية

```
لوحة التحكم → الثيمات الديناميكية → اختر ويدجت → العناصر الفرعية
```

### الخطوة 2: اختيار عنصر فرعي

1. من قائمة "العناصر الفرعية" على اليسار
2. اضغط على العنصر الذي تريد تحريره
3. سيظهر في القسم الأوسط محرر كامل للعنصر

### الخطوة 3: تحرير الشكل

```
محرر التصميم → الشكل
├── تقوس الزوايا (0-50 بكسل)
├── الموضع (أفقي وعمودي)
├── الأبعاد (عرض وارتفاع)
```

**مثال:**
- تقوس الزوايا = 10 بكسل ← عناصر بزوايا دائرية
- الموضع = (100, 50) ← العنصر يبدأ من هذا الموضع
- الأبعاد = (200x150) ← عرض 200 بكسل وارتفاع 150 بكسل

### الخطوة 4: تحديد الألوان

```
محرر التصميم → الألوان
├── الخلفية
│   ├── اختر لون من اللوحة
│   ├── أو أدخل كود HEX (#ffffff)
├── النص
│   ├── اختر لون مناسب
├── الحدود
│   ├── لون حد العنصر
```

**نصائح اللون:**
- استخدم ألوان متناسقة
- تأكد من التباين بين النص والخلفية
- استخدم Presets للألوان الموصى بها

### الخطوة 5: إضافة الحدود

```
محرر التصميم → الحدود
├── السمك (0-10 بكسل)
├── النوع (صلب، متقطع، نقاط)
├── اللون
```

**أمثلة:**
- حد رفيع صلب ← احترافي وبسيط
- حد سميك متقطع ← ديناميكي وجريء
- بدون حد ← تصميم بسيط

### الخطوة 6: إضافة ظلال

```
محرر التصميم → الظلال
├── الإزاحة الأفقية (-20 إلى 20)
├── الإزاحة العمودية (-20 إلى 20)
├── الضبابية (0-50 بكسل)
├── الشفافية (0-1)
```

**أمثلة:**
```
ظل بسيط: Offset 0,2 | Blur 4 | Opacity 0.1
ظل متوسط: Offset 2,4 | Blur 8 | Opacity 0.2
ظل قوي: Offset 4,8 | Blur 16 | Opacity 0.3
```

### الخطوة 7: إضافة حركات

```
محرر التصميم → الحركات
├── نوع الحركة
│   ├── Fade (اختفاء وظهور)
│   ├── Slide (انزلاق جانبي)
│   ├── Bounce (قفزة)
│   ├── Pulse (نبضة)
├── السرعة (بالميلي ثانية)
├── التأخير
```

**استخدام الحركات:**
```
الدخول: استخدم Fade أو Slide عند ظهور الصفحة
التركيز: استخدم Pulse لجذب الانتباه
التأكيد: استخدم Bounce للعناصر المهمة
```

### الخطوة 8: مراجعة المعاينة

1. انظر إلى القسم الأيمن "المعاينة"
2. شاهد كيف يبدو العنصر بجميع التأثيرات
3. اقرأ كود CSS المولد

### الخطوة 9: حفظ التغييرات

```
اضغط على زر "حفظ التغييرات" (الزر الأزرق)
انتظر الرسالة الخضراء "تم الحفظ بنجاح"
```

## 🎨 أمثلة عملية

### مثال 1: عنوان احترافي

**المتطلبات:**
- لون خلفية فاتح
- نص أسود غامق
- حد رفيع
- ظل خفيف

**الخطوات:**
```javascript
{
    shape_config: {
        borderRadius: 5
    },
    color_config: {
        background: "#f8f9fa",
        text: "#212529"
    },
    border_config: {
        width: 1,
        style: "solid",
        color: "#dee2e6"
    },
    shadow_config: {
        offsetX: 0,
        offsetY: 2,
        blur: 4,
        opacity: 0.1
    }
}
```

### مثال 2: زر بارز

**المتطلبات:**
- لون خلفية زاهي
- نص أبيض
- حدود مستديرة
- ظل قوي

**الخطوات:**
```javascript
{
    shape_config: {
        borderRadius: 25
    },
    color_config: {
        background: "#007bff",
        text: "#ffffff"
    },
    border_config: {
        width: 0,
        style: "solid",
        color: "transparent"
    },
    shadow_config: {

        offsetY: 4,
        blur: 8,
        opacity: 0.2
    },
    animation_config: {
        type: "pulse",
        duration: 1000
    }
}
```

**المتطلبات:**
- خلفية بيضاء
- حدود رمادية
- ظل متوسط
- حركة دخول

**الخطوات:**
```javascript

        borderRadius: 8
    },

        background: "#ffffff",
        text: "#333333"
    },
    border_config: {
        width: 1,
        style: "solid",
        color: "#e0e0e0"

        offsetX: 0,
        offsetY: 2,
        blur: 8,
```

## 🎓 نصائح مفيدة

### 1. اختيار الألوان الجيدة
```
✓ استخدم Presets الموصى بها
✓ تأكد من التباين (WCAG Standards)
✓ استخدم ألوان متناسقة (Color Harmony)
✓ تجنب الألوان الصارخة
```

### 2. تصميم متوازن
```
✓ لا تكثر من الحدود والظلال
✓ استخدم المسافات البيضاء بحكمة
✓ حافظ على التسلسل الهرمي البصري
✓ اختبر على أحجام مختلفة
```

### 3. حركات فعالة
```
✓ استخدم حركات بطيئة (200-500ms) للأناقة
✓ استخدم حركات سريعة (100-200ms) للديناميكية
✓ تجنب الحركات المزعجة
✓ اختبر على أجهزة مختلفة
```

### 4. الأداء
```
✓ قلل عدد الظلال القوية
✓ تجنب الحركات المعقدة
✓ استخدم الألوان الثابتة بدل الـ Gradients
✓ اختبر سرعة التحميل
```

## ❌ مشاكل شائعة وحلولها

### المشكلة: العنصر لا يظهر
```
السبب: قد يكون مخفياً أو معطلاً
الحل:
1. تحقق من خيار "عرض العنصر" ✓
2. تحقق من خيار "العنصر مفعل" ✓
3. تحقق من الألوان (هل هي نفس لون الخلفية؟)
4. حاول تصفير الشاشة (Ctrl+F5)
```

### المشكلة: الألوان مختلفة عن المتوقع
```
السبب: قد يكون هناك تأثير من CSS أخرى
الحل:
1. جرب الألوان بشكل أساسي
2. استخدم أداة Color Picker للتأكد
3. تحقق من الـ Presets المطبقة
4. أعد تحميل الصفحة
```

### المشكلة: الحركات بطيئة جداً
```
السبب: سرعة المعالج أو الإنترنت
الحل:
1. قلل سرعة الحركة (مثل 200ms بدل 1000ms)
2. استخدم حركات أبسط
3. تحقق من أداء الجهاز
4. اختبر على جهاز آخر
```

### المشكلة: الظل لا يظهر
```
السبب: قد تكون الشفافية صفر
الحل:
1. تأكد أن قيمة الشفافية > 0
2. تأكد من قيمة الضبابية > 0
3. جرب ظل أقوى (opacity 0.3)
4. افحص كود CSS المولد
```
