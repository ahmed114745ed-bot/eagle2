# 🚀 البدء السريع

## في 3 خطوات فقط!

### 1️⃣ التثبيت
```bash
php artisan migrate
npm run build
```

### 2️⃣ الاستخدام في Vue
```vue

```

### 3️⃣ الاستمتاع بالنتائج! 🎉

---

## 📋 قائمة السريعة

| العملية | الأمر/الكود |
|--------|----------|
| تثبيت DB | `php artisan migrate` |
| بناء Assets | `npm run build` |
| تشغيل Tests | `php artisan test` |
| API: إنشاء | `POST /api/customizers` |
| API: قراءة | `GET /api/customizers/1` |
| API: تحديث | `PUT /api/customizers/1` |
| API: حذف | `DELETE /api/customizers/1` |
