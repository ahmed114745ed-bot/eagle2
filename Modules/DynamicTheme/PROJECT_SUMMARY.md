## 🎓 أمثلة الاستخدام

### مثال 1: في Vue Component
```vue
<WidgetEditorComponent
  :config-widget-override-id="activeWidgetId"
  @save="onSave"
  @error="onError"
/>
```

### مثال 2: في PHP
```php
use Modules\DynamicTheme\Services\CustomizerService;

$customizer = CustomizerService::createCustomizer(
    1,
    ['color_config' => [...]]
);

$css = CustomizerService::getCustomizerCSS(1);
```

### مثال 3: API Call
```javascript
axios.post('/api/customizers', {
  config_widget_override_id: 1,
  color_config: { primary: '#3b82f6' }
})
```
