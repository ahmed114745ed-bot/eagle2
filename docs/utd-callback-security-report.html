🔐 Webhook Signature Verification (HMAC-SHA256)

الـ webhook بين UTD و Eagle محمي بـ HMAC-SHA256 signature عشان نتأكد إن الريكوست جاي فعلا من UTD مش من حد تاني.

كيف بيشتغل:

الخطوة التفاصيل
1. التوليد الأدمن بيولد Webhook Secret من داشبورد UTD (صفحة تفاصيل المشروع)
2. التسجيل نفس الـ Secret بيتحط في إعدادات Eagle من
Admin → Settings → Payment → UTD → Webhook Secret
3. التوقيع UTD بيبعت هيدرز مع كل webhook request:
X-UTD-Signature: hmac_sha256(timestamp + '.' + body, secret)
X-UTD-Timestamp: unix_timestamp
4. التحقق Middleware VerifyUtdPayWebhook في Eagle بيتحقق من:
  • ✔ وجود الهيدرز X-UTD-Signature و X-UTD-Timestamp
  • ✔ الـ timestamp في آخر 5 دقايق (حماية من Replay)
  • ✔ الـ signature صحيح (HMAC-SHA256 match)

الإعداد:

المكان الإجراء
UTD Dashboard
(Admin)		 اضغط "توليد Webhook Secret" في كارت API Keys جوا تفاصيل المشروع
Eagle Admin انسخ الـ Secret وحطه في Settings → Payment → UTD → Webhook Secret
⚠ ملاحظة: لو الـ Webhook Secret فاضي في Eagle، الميدل وير بيعدي الريكوست من غير تحقق (عشان مش يكسر حاجة قبل ما يتظبط).
