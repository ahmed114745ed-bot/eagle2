1.2 Database Tables

The package will create/modify the following tables:

  • users - Adds special_id column
  • wares - Adds value column
  • special_id_histories - Special ID purchase/usage history
  • user_wares - User-ware relationships
  • special_id_frams - Special ID frames

2. Installation Steps

1 Copy the Package

Copy the SpecialId folder to your project:

packages/Utd/SpecialId
2 Update composer.json

Add the package path to your composer.json repositories section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/SpecialId"
        }
    ]
}
3 Install the Package 
composer require utd/special-id
4 Run Setup Commands

Run migrations, seeders, and clear cache:

php artisan migrate
php artisan db:seed --class=Utd\SpecialId\Database\Seeders\SpecialIdDatabaseSeeder
php artisan db:seed --class=PermissionTypeSeeder
php artisan optimize:clear

3. Configuration

3.1 Publish Configuration

php artisan vendor:publish --tag=config

The config file will be published to config/specialid.php.

7. Troubleshooting

Issue: Page Not Found (404)

Solution:
php artisan optimize:clear

Issue: Migration Errors

Solution:
php artisan migrate:status
php artisan migrate

Issue: Class Not Found Errors

Solution:
composer dump-autoload
php artisan cache:clear

Issue: Admin Menu Not Showing

Solution:
php artisan db:seed --class=Utd\SpecialId\Database\Seeders\SpecialIdDatabaseSeeder

7.1 Rollback Migrations

php artisan migrate:rollback --path=packages/Utd/SpecialId/Database/Migrations
