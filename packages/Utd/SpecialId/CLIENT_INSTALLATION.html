🏷️ SpecialId Package
Installation Guide

Requirements

  • PHP 8.1 or higher
  • Laravel 10.x or 11.x
  • MySQL 5.7 or higher
  • Laravel-Admin package installed

Installation Steps

1 Copy the Package

Copy the SpecialId folder to:

packages/Utd/SpecialId
2 Update composer.json

Add this to your project's composer.json in the "repositories" section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/SpecialId"
        }
    ]
}
3 Install the Package 
composer require utd/special-id
4 Run Setup Commands

Run migrations, seeders, and clear cache:

php artisan migrate; php artisan db:seed --class=Utd\SpecialId\Database\Seeders\SpecialIdDatabaseSeeder; php artisan db:seed --class=PermissionTypeSeeder; php artisan optimize:clear

Verify Installation

Open your browser and go to:

https://your-domain.com/admin/special-wares
✅ Done! If the page loads, your installation is complete.

Configuration (Optional)

Publish the config file:

php artisan vendor:publish --tag=config
⚠️ Having Issues?
Run: 
php artisan route:list | findstr special
If no routes appear, contact support.
