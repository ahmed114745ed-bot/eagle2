دليل شامل للتثبيت والإزالة والاستخدام

ℹ️ معلومات الحزمة

المعلومة القيمة
اسم الحزمة utd/bd
النوع حزمة اختيارية (Optional Package)
المسار packages/Utd/Bd
Service Provider Utd\Bd\BdServiceProvider::class
الوصف نظام إدارة مطوري الأعمال (Business Developers)

⚙️ خطوات التثبيت

الطريقة 1: باستخدام Composer (الموصى بها)

1 تثبيت الحزمة عبر Composer:
composer require utd/bd
2 مسح الـ Cache:
php artisan config:clear php artisan cache:clear php artisan optimize:clear
3 إعادة بناء Autoload:
composer dump-autoload
4 تشغيل Migrations (إذا لزم الأمر):
php artisan migrate
5 نشر الـ Assets (إذا كانت موجودة):
php artisan vendor:publish --provider="Utd\Bd\BdServiceProvider"

الطريقة 2: التثبيت اليدوي

1 إضافة في composer.json في قسم require:
"utd/bd": "*"
2 إضافة في composer.json في قسم repositories:
{ "type": "path", "url": "packages/Utd/Bd" }
3 إضافة Service Provider في config/app.php:
Utd\Bd\BdServiceProvider::class,
4 تحديث Dependencies:
composer update utd/bd

✅ التحقق من التثبيت:

php artisan tinker PackageHelper::isInstalled('bd')

إذا كانت النتيجة true فالحزمة مثبتة بنجاح

🗑️ خطوات الإزالة (بدون حذف البيانات)

⚠️ تحذير مهم:

الخطوات التالية تزيل الحزمة من التطبيق ولكن تحتفظ بالبيانات والملفات

  • ✅ البيانات في قاعدة البيانات تبقى محفوظة
  • ✅ ملفات الحزمة في packages/Utd/Bd/ تبقى محفوظة
  • ✅ يمكن إعادة التثبيت في أي وقت

الطريقة 1: باستخدام Composer (الموصى بها)

1 إزالة الحزمة عبر Composer:
composer remove utd/bd

هذا الأمر يزيل الحزمة من vendor/ ولكن يبقي الملفات في packages/

2 حذف/تعطيل Service Provider من config/app.php:
// Utd\Bd\BdServiceProvider::class, // Package uninstalled
3 حذف ملفات الـ Cache:
rm -f bootstrap/cache/services.php rm -f bootstrap/cache/packages.php rm -f bootstrap/cache/config.php
4 مسح الـ Cache وإعادة البناء:
composer dump-autoload php artisan config:clear php artisan cache:clear php artisan optimize:clear

الطريقة 2: الإزالة اليدوية

1 حذف من composer.json من قسم require:
// احذف هذا السطر: "utd/bd": "*"
2 حذف من composer.json من قسم repositories:
// احذف هذا القسم: { "type": "path", "url": "packages/Utd/Bd" }
3 تعطيل Service Provider في config/app.php:
// Utd\Bd\BdServiceProvider::class,
4 تحديث Composer:
composer update composer dump-autoload

✅ التحقق من الإزالة:

composer show utd/bd # النتيجة: Package "utd/bd" not found php artisan tinker PackageHelper::isInstalled('bd') # النتيجة: false

📁 الملفات المحفوظة بعد الإزالة:

  • مجلد الحزمة: packages/Utd/Bd/ (كامل)
  • الجداول: bd_*, admin_users (WHERE type='bd')
  • الـ Routes: محمية في routes/web.php بـ PackageHelper::isInstalled('bd')
  • Config: أي ملفات configuration تم نشرها

🛡️ Routes المحمية

جميع routes الخاصة بالحزمة محمية بفحص التثبيت، لن تظهر أخطاء إذا كانت الحزمة غير مثبتة:

// في routes/web.php // ✅ Route محمي if (PackageHelper::isInstalled('bd')) { Route::get('/sync-bd-agencies', [\Utd\Bd\Http\Controllers\Admin\BdController::class, 'sync']); } // ✅ Route محمي if (PackageHelper::isInstalled('bd')) { Route::get('/migrate-bd-salaries', [\Utd\Bd\Http\Controllers\BdSalaryMigrationController::class, 'migrate']); } // ✅ Route محمي Route::get('assign-super-admin-bd', function () { if (!PackageHelper::isInstalled('bd')) { return "BD package is not installed."; } // ... الكود });

🔄 إعادة التثبيت

لإعادة تثبيت الحزمة بعد إزالتها (البيانات والملفات محفوظة):

1 تثبيت الحزمة:
composer require utd/bd
2 تفعيل Service Provider في config/app.php:
Utd\Bd\BdServiceProvider::class,
3 مسح الـ Cache:
php artisan config:clear php artisan cache:clear composer dump-autoload

✅ جاهز!

الحزمة الآن مثبتة مع جميع البيانات السابقة محفوظة

🔧 استكشاف الأخطاء الشائعة

خطأ: Class "Utd\Bd\BdServiceProvider" not found

الحل:

# 1. حذف ملفات الـ cache rm -f bootstrap/cache/*.php # 2. مسح الـ cache php artisan config:clear php artisan cache:clear # 3. إعادة بناء autoload composer dump-autoload

خطأ: Target class [BdController] does not exist

الحل:

استخدم Full namespace في الـ routes:

// ❌ خطأ use App\Admin\Controllers\BdController; // ✅ صحيح if (PackageHelper::isInstalled('bd')) { Route::get('/route', [\Utd\Bd\Http\Controllers\Admin\BdController::class, 'method']); }

خطأ: Table 'bd_*' doesn't exist

الحل:

# تشغيل migrations php artisan migrate # أو تشغيل migrations محددة php artisan migrate --path=/packages/Utd/Bd/database/migrations
