1.3 Database Tables

The package will create the following tables and views:

  • wallet_templates - Wallet template definitions (bank, digital wallet, etc.)
  • wallet_fields - Custom fields for each wallet template
  • wallets - User wallet records with balances
  • wallet_logs - Transaction logs for wallet operations
  • user_withdrawals - User withdrawal requests
  • user_diamond_logs - Diamond transaction history
  • all_user_logs (view) - Combined view of all user logs
  • wallet_logs_view (view) - Wallet logs aggregation view

2. Installation Steps

1 Copy the Package

Copy the UsersWallet folder to your project:

packages/Utd/UsersWallet
2 Update composer.json

Add the package path to your composer.json repositories section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/UsersWallet",
            "options": {
                "symlink": true
            }
        }
    ]
}

And add the package to the require section:

"utd/users-wallet": "*"
3 Install the Package

Run composer require:

composer require utd/users-wallet
4 Register in PackageHelper

Add the UsersWallet package to app/Support/PackageHelper.php:

use Utd\UsersWallet\Entities\UserWallet;

// Add to the $packages array:
'usersWallet' => UserWallet::class,
5 Run Migrations 
php artisan migrate
6 Run Database Seeders

Run the wallet seeders to set up admin menu and wallet templates:

php artisan db:seed --class="Utd\UsersWallet\Database\Seeders\WalletMenuSeeder"
php artisan db:seed --class="Utd\UsersWallet\Database\Seeders\BankAccountTemplateSeeder"
php artisan db:seed --class="Utd\UsersWallet\Database\Seeders\DigitalWalletTemplateSeeder"
php artisan db:seed --class="Utd\UsersWallet\Database\Seeders\OtherWalletTemplateSeeder"
7 Update Admin Permissions

Run the permissions seeder to add Wallet permissions:

php artisan db:seed --class=PermissionTypeSeeder
8 Clear Cache 
php artisan cache:clear
php artisan config:clear
php artisan route:clear
php artisan view:clear

3. Configuration

3.1 Publish Configuration

Optionally publish the config file to customize settings:

php artisan vendor:publish --tag=config --provider="Utd\UsersWallet\UsersWalletServiceProvider"

This publishes the config to config/userswallet.php.

3.2 Publish Views

Optionally publish views for customization:

php artisan vendor:publish --tag=userswallet-module-views

Views will be published to resources/views/modules/userswallet/.

3.3 Wallet Templates

The package comes with 3 pre-built wallet templates:

Template Seeder Purpose
Bank Account BankAccountTemplateSeeder Bank transfer withdrawal method
Digital Wallet DigitalWalletTemplateSeeder E-wallet withdrawal method (Vodafone Cash, etc.)
Other OtherWalletTemplateSeeder Custom/other withdrawal methods

3.4 External File Guards

The following external files use PackageHelper::isInstalled('usersWallet') guards and will gracefully degrade when the package is not installed:

  • app/helper/helpers.php - wallet_available_by_user(), wallet_curant_by_user()
  • app/Admin/Controllers/AllStatisticController.php - Withdrawals query, ajaxWalletLogs()
  • app/Admin/Controllers/UserController.php - wallet_logs case
  • app/Tik/Services/ChargeRepoService.php - WalletTransactionService calls
  • app/Bd/Controllers/WalletController.php - WalletTransactionService calls
  • Modules/SuperAdmin/Http/Controllers/SuperAdmin/WalletController.php - WalletTransactionService calls
  • Modules/AreaManager/Http/Controllers/WalletController.php - WalletTransactionService calls
  • app/Observers/UserSallaryObserver.php - UpdateUserWalletBalances dispatch
  • database/seeders/PermissionTypeSeeder.php - Wallet permissions (spread operator pattern)

7. Troubleshooting

7.1 Common Issues

Issue: Page Not Found (404)

Solution: 
php artisan route:clear
php artisan cache:clear
php artisan config:clear

Issue: Class Not Found Error

Solution: 
composer dump-autoload
php artisan package:discover

Issue: Admin Menu Not Showing

Solution:
  1. Run the menu seeder: php artisan db:seed --class="Utd\UsersWallet\Database\Seeders\WalletMenuSeeder"
  2. Clear cache: php artisan cache:clear
  3. Check that "Wallet" parent menu exists in the admin_menu table

Issue: "Column already exists" on Migration

Solution:

If feature_type column already exists in user_coin_logs:

  1. Manually insert the migration record to skip it:
php artisan tinker
DB::table('migrations')->insert([
    'migration' => '2025_11_26_111617_add_feature_type_to_user_coin_logs',
    'batch' => DB::table('migrations')->max('batch') + 1
]);

Then re-run php artisan migrate.

Issue: View Already Exists

Solution:

If database views already exist from a previous installation:

php artisan tinker
DB::statement('DROP VIEW IF EXISTS all_user_logs');
DB::statement('DROP VIEW IF EXISTS wallet_logs_view');

Then re-run php artisan migrate.

Issue: Wallet Functions Return 0

Solution:
  1. Verify 'usersWallet' => UserWallet::class is in PackageHelper
  2. Verify Utd\UsersWallet\Entities\UserWallet class exists
  3. Run composer dump-autoload

Issue: WalletTransactionService Not Found in External Files

Solution:

External files reference Utd\UsersWallet\Services\WalletTransactionService. Ensure the package is installed and autoloaded:

composer dump-autoload
php artisan config:clear

9. Key Services & Classes

The package provides the following key services used internally and by external files:

Class Namespace Purpose
WalletService Utd\UsersWallet\Services Core wallet operations (transfer, profits, transactions, history)
WalletTransactionService Utd\UsersWallet\Services Store wallet transactions (used by external BD/SuperAdmin/AreaManager controllers)
ExchangeService Utd\UsersWallet\Services Diamond exchange operations
WalletHelper Utd\UsersWallet\Helpers Helper functions (createWithdrawal, addAllBalancesByDiffs)
UpdateUserWalletBalances Utd\UsersWallet\Jobs Queue job for recalculating wallet balances
Important Notes
  • External files use PackageHelper::isInstalled('usersWallet') guards — all wallet functionality gracefully degrades when the package is removed
  • WalletTransactionService is called statically from external controllers — no constructor injection needed
  • The UpdateUserWalletBalances job is dispatched from UserSallaryObserver — it requires a queue worker to be running
