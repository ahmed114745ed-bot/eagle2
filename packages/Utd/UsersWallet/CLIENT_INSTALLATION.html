💰 UsersWallet Package
Installation Guide

Requirements

  • PHP 8.1 or higher
  • Laravel 10.x or 11.x
  • MySQL 5.7 or higher
⚠️ No Required Dependencies
This package works independently. No other packages are required.

Installation Steps

1 Copy the Package

Copy the UsersWallet folder to:

packages/Utd/UsersWallet
2 Update composer.json

Add this to your project's composer.json in the "repositories" section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/UsersWallet"
        }
    ]
}
3 Install the Package 
composer require utd/users-wallet
4 Run Setup Commands

Run migrations, seeders, and clear cache:

php artisan migrate; php artisan db:seed --class="Utd\UsersWallet\Database\Seeders\UsersWalletDatabaseSeeder"; php artisan db:seed --class="Utd\UsersWallet\Database\Seeders\WalletMenuSeeder"; php artisan db:seed --class=PermissionTypeSeeder; php artisan optimize:clear

Verify Installation

Test the routes:

php artisan route:list | findstr wallet

Open your browser and go to:

https://your-domain.com/admin/wallet-templates
https://your-domain.com/admin/wallet-withdrawal
✔️ Done! If wallet routes appear and the admin pages load, your installation is complete.

What This Package Provides

  • User wallets with balance, cut amount, and pending amount tracking
  • Wallet transaction logs (add, cut, pending operations)
  • Withdrawal requests management (approve/reject)
  • Wallet templates and custom fields configuration
  • Diamond exchange functionality
  • Wallet balance recalculation and validation utilities
⚠️ Having Issues?
Ensure cache is cleared and routes are registered: 
php artisan optimize:clear
php artisan route:list | findstr wallet
