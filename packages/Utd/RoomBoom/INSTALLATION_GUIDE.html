1. Overview

1.1 What is Room Boom?

Room Boom is a gamification feature that rewards users for sending gifts in rooms. When a room reaches certain gift thresholds (levels), it triggers a "boom" event with rewards for top contributors.

1.2 Key Features

  • Boom Levels - Configurable gift thresholds that trigger boom events
  • Top Contributors - Tracks and rewards users who contribute the most gifts
  • Winners - Records boom winners for each level
  • Super Boom Rules - Special rules for enhanced boom events
  • Real-time Tracking - Live tracking of room gift totals

1.3 How It Works

  1. Users send gifts in a room
  2. System tracks total gift value for the day
  3. When total reaches a boom level's min_target, boom starts
  4. When total reaches the level's target, boom ends
  5. Top contributors receive rewards
  6. Next boom level can start automatically

2.2 Required Dependencies

Package Purpose Required
Utd/Room Room system (provides TotalRoomGift) Yes
⚠️ Important

The Utd/Room package must be installed and migrated before installing Room Boom, as it depends on the total_room_gifts table.

2.3 Database Tables

The package will create the following tables:

Core Tables

  • room_boom_levels - Boom level definitions (targets, rewards)
  • room_booms - Active and completed boom records
  • room_boom_gifts - Gift contributions tracking
  • room_boom_rewards - Reward configurations per level

Additional Tables

  • room_boom_top_contributors - Top contributor records
  • room_boom_winners - Boom winners history
  • super_boom_rules - Special boom rules

3. Installation Steps

1 Copy the Package

Copy the RoomBoom folder to your project:

packages/Utd/RoomBoom
2 Update composer.json

Add the package path to your composer.json repositories section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/RoomBoom"
        }
    ]
}
3 Install the Package

Run composer require:

composer require utd/room-boom
4 Run Setup Commands

Run migrations, seeders, and clear cache (all in one command):

php artisan migrate; php artisan db:seed --class=Utd\RoomBoom\Database\Seeders\RoomBoomDatabaseSeeder; php artisan optimize:clear

4. Configuration

4.1 Environment Variables

Add these to your .env file:

# Room Boom Package Configuration
ROOM_BOOM_ENABLED=true

4.2 Publish Configuration

Publish the configuration file (if available):

php artisan vendor:publish --tag=roomboom-config

4.3 Contract Binding

The package automatically binds the following contract:

App\Contracts\NewRoomBoomGiftServiceContract
→ Utd\RoomBoom\Services\NewRoomBoomGiftService

If the package is not installed, a null implementation is used:

App\Contracts\NewRoomBoomGiftServiceContract
→ App\Services\Null\NullNewRoomBoomGiftService

5. Database Tables Reference

5.1 room_boom_levels

Defines the boom levels and their thresholds.

Column Type Description
id bigint Primary key
level integer Level number (1, 2, 3...)
min_target integer Minimum gift total to start boom
target integer Gift total to complete boom
video string Video URL for boom animation

5.2 room_booms

Tracks active and completed boom events.

Column Type Description
id bigint Primary key
total_room_gift_id bigint Reference to total_room_gifts
room_boom_level_id bigint Reference to boom level
started_at timestamp When boom started
ended_at timestamp When boom ended (null if active)
total_gifts_value integer Total gift value at boom end

5.3 room_boom_gifts

Tracks individual gift contributions during a boom.

Column Type Description
id bigint Primary key
total_room_gift_id bigint Reference to total_room_gifts
user_id bigint User who sent the gift
price integer Gift value
room_boom_level integer Boom level when gift was sent
start_boom_ranking tinyint Whether gift counts for ranking

5.4 room_boom_rewards

Reward configurations for each boom level.

Column Type Description
id bigint Primary key
room_boom_level_id bigint Reference to boom level
rank integer Reward rank (1st, 2nd, 3rd...)
reward_type string Type of reward (coins, diamonds, etc.)
reward_value integer Reward amount

8. Troubleshooting

8.1 Common Issues

Issue: Page Not Found (404)

Solution: 
php artisan optimize:clear

Issue: Migration Errors (Foreign Key)

Solution:

Ensure Utd/Room package is installed and migrated first:

# Install Room package first
composer require utd/room
php artisan migrate

# Then install Room Boom
composer require utd/room-boom
php artisan migrate

Issue: Class Not Found Errors

Solution: 
composer dump-autoload
php artisan cache:clear

Issue: Admin Menu Not Showing

Solution:

Run the database seeder:

php artisan db:seed --class=Utd\RoomBoom\Database\Seeders\RoomBoomDatabaseSeeder

Issue: Contract Binding Error

Solution:

Ensure the contract exists in app/Contracts:

App\Contracts\NewRoomBoomGiftServiceContract

And the null service exists:

App\Services\Null\NullNewRoomBoomGiftService

8.2 Rollback Migrations

To rollback room boom migrations:

# Rollback all room boom migrations
php artisan migrate:rollback --path=packages/Utd/RoomBoom/Database/migrations

# Or rollback specific batch
php artisan migrate:rollback --step=1

8.3 Log Files

Check Laravel logs for detailed error information:

storage/logs/laravel.log
