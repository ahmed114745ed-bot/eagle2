# إدارة حزمة Family (تثبيت وإزالة)

تم توفير أوامر Artisan لتسهيل عملية إدارة الحزمة.

## 🚀 التثبيت (Installation)

لتثبيت الحزمة ونشر ملفات الإعدادات والتهجيرات:

```bash
php artisan family:install
```

سيقوم هذا الأمر بـ:
1. نشر ملف الإعدادات `config/family.php`.
2. تشغيل التهجيرات (Migrations) الخاصة بالحزمة.
3. إضافة الحزمة إلى `composer.json` إذا لم تكن موجودة.

---

## 🗑️ إزالة التثبيت (Uninstallation)

لإزالة الحزمة بالكامل مع حذف الجداول والأعمدة المضافة:

```bash
php artisan family:uninstall
```

### الخيارات المتاحة:

*   `--force`: التنفيذ مباشرة دون طلب تأكيد.
*   `--keep-data`: حذف الأعمدة المضافة فقط (مثل `family_id` في جدول `users`) مع الاحتفاظ بالجداول الخاصة بالحزمة (مثل `families`).

**⚠️ تحذير:** هذا الأمر سيحذف جميع بيانات الـ Families والـ Family Members بشكل نهائي ما لم يتم استخدام خيار `--keep-data`.

---

## 🛠️ الخطوات اليدوية (بعد الإزالة)

بعد تنفيذ أمر الإزالة، يرجى القيام بـ:

1. تحديث الـ Autoload:
    ```bash
    composer dump-autoload
    ```
2. حذف مجلد الحزمة (اختياري):
    ```bash
    rm -rf packages/Utd/Family
    ```
