1. Overview

1.1 What is Role Rewards?

Role Rewards is a package that enables administrators to assign rewards (VIP, Wares, Badges, Achievements) to admin roles. When a user is assigned a role, they automatically receive the configured rewards. When the role is removed, the rewards are revoked.

1.2 Key Features

  • Role-based Rewards - Configure rewards per admin role
  • Multiple Reward Types - Support for Wares, VIP, Badges, and Achievements
  • Automatic Sync - Rewards are granted/revoked automatically on role changes
  • Expiration Support - Time-limited rewards with configurable expiry
  • Safe Install/Uninstall - Contract pattern with null fallback

1.3 How It Works

  1. Admin navigates to /admin/auth/roles
  2. Clicks the "Rewards" button on any role
  3. Adds rewards (Ware, VIP, Badge, Achievement) with optional expiry
  4. When a user gets assigned that role, rewards are automatically granted
  5. When the role is removed, rewards are automatically revoked

3. Installation Steps

1 Copy the Package

Copy the RoleRewards folder to your project:

packages/Utd/RoleRewards
2 Update composer.json

Add the package path to your composer.json repositories section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/RoleRewards"
        }
    ]
}
3 Install the Package

Run composer require:

composer require utd/role-rewards
4 Run Migrations & Clear Cache

Run migrations to create database tables and clear cache:

php artisan migrate; php artisan optimize:clear
Note

The package uses the Contract/Null Object pattern. No additional configuration is needed — it works out of the box.

4. How It Works

4.1 Contract Pattern

The package uses the Contract/Null Object pattern for safe install/uninstall:

  • When installed: RoleRewardContract resolves to RoleRewardService (real implementation)
  • When uninstalled: RoleRewardContract resolves to NullRoleRewardService (does nothing)
Fallback Behavior

If the Role Rewards package is not installed, the application will use NullRoleRewardService as a fallback, doing nothing instead of throwing errors.

4.2 Reward Types

Type Description Dependency
Ware Items from the wares/shop system Built-in
VIP VIP packages Requires Utd/Vip package
Badge Badges from the badge system Requires Badge module
Achievement Achievement rewards Requires Utd/Achievements package

4.3 Automatic Sync

When a role is assigned or removed from a user, the package automatically:

  • Grants all configured rewards for that role
  • Revokes rewards when the role is removed
  • Handles expiration for time-limited rewards

5. Routes

5.1 Web Routes (Admin Panel)

Base route: /admin/auth/roles → Click rewards button on any role

Method Endpoint Description
GET /admin/role-rewards/{role_id} List rewards for a role
GET /admin/role-rewards/{role_id}/create Create reward form
POST /admin/role-rewards/{role_id} Store new reward
GET /admin/role-rewards/{role_id}/{id}/edit Edit reward form
PUT /admin/role-rewards/{role_id}/{id} Update reward
DELETE /admin/role-rewards/{role_id}/{id} Delete reward

Click the rewards button on any role to access:

https://your-domain.com/admin/role-rewards/{role_id}
Success! If all checks pass, the Role Rewards package is properly installed and configured.

7. Troubleshooting

7.1 Common Issues

Package Not Found

Error: Package utd/role-rewards not found

Ensure the package path is correctly added to composer.json repositories and run composer update.

Route Not Found

Error: 404 on role-rewards routes

Clear route cache: php artisan route:clear and verify the service provider is registered.

Class Not Found

Error: Class 'Utd\RoleRewards\...' not found

Run composer dump-autoload and clear all caches.

7.2 Useful Commands

# Clear all caches
php artisan optimize:clear

# Re-discover packages
composer dump-autoload

# Check service provider registration
php artisan package:discover
