Overview

The Room Cup package provides a competition system for rooms. Rooms earn points based on gifts received, and top-performing rooms win rewards. Room owners and admins can both earn rewards based on configurable target thresholds.

⚠️ Dependency Required:
This package depends on Utd/Room package. Ensure it is installed before installing Room Cup.

Installation

Step 1: Copy Package

Copy the RoomCup folder to your packages directory:

packages/Utd/RoomCup
Step 2: Update composer.json

Add the repository and require the package:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/RoomCup",
            "options": {
                "symlink": true
            }
        }
    ],
    "require": {
        "utd/room-cup": "*"
    }
}
Step 3: Install via Composer
composer update utd/room-cup
Step 4: Run Migrations
php artisan migrate
Step 5: Run Seeders
php artisan db:seed --class=PermissionTypeSeeder; php artisan db:seed --class="Utd\RoomCup\Database\Seeders\RoomCupDatabaseSeeder"
Step 6: Clear Cache
php artisan optimize:clear
✅ Installation Complete!
The package is now installed and ready to use.

Configuration

Environment Variables

# Enable/disable room cup feature
ROOM_CUP_ENABLED=true

# Cup type: daily, weekly, monthly
ROOM_CUP_TYPE=daily

Publish Configuration (Optional)

php artisan vendor:publish --tag=roomcup-config

API Endpoints

MethodEndpointDescription
GET/api/v3/room-cup/targetsGet cup targets list
GET/api/v3/room-cup/targets/{roomId}Get targets for specific room
GET/api/v3/room-cup/rewardsGet user's rewards
POST/api/v3/room-cup/rewards/{id}/claimClaim a reward

Artisan Commands

Calculate Rewards

php artisan roomcup:calculate-rewards

Calculates and distributes rewards to qualifying rooms. Schedule this in your Kernel.php:

$schedule->command('roomcup:calculate-rewards')->dailyAt('00:00');

Package Removal

⚠️ Warning: Removing this package will delete all room cup data!
Step 1: Remove Package
composer remove utd/room-cup
Step 2: Rollback Migrations (Optional)
php artisan migrate:rollback --path=packages/Utd/RoomCup/Database/migrations
Step 3: Remove Repository Entry

Remove the RoomCup repository entry from composer.json.

Step 4: Delete Package Folder
rm -rf packages/Utd/RoomCup
Step 5: Clear Cache
php artisan optimize:clear
