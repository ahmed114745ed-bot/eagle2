1. Overview

1.1 What is Charizma?

Charizma is a feature that tracks and displays user earnings/contributions within rooms. It provides real-time tracking of user activity and earned coins while on microphone positions in rooms.

1.2 Key Features

  • Room Charizma Tracking - Tracks user earnings per room
  • Microphone Position Integration - Links charizma data to mic positions
  • Charizma Status Toggle - Enable/disable charizma per room
  • Automatic Reset - Reset charizma data with scheduled jobs
  • Real-time Updates - Live tracking of user contributions

1.3 How It Works

  1. Room owner enables charizma status for their room
  2. Users join microphone positions in the room
  3. System tracks earnings/contributions for each user
  4. Charizma data is stored in extra_data_in_rooms table
  5. Data can be reset manually or via scheduled jobs

2. Requirements

2.1 Backend Requirements

Requirement Minimum Version Status
PHP 8.1 or higher ✓
Laravel Framework 10.x or 11.x ✓
Laravel Sanctum Latest ✓
MySQL 5.7 or higher ✓

2.2 Required Dependencies

Package Purpose Required
Utd/Room Room system (provides Room model & microphones) Yes
⚠️ Important

The Utd/Room package must be installed and migrated before installing Charizma, as it depends on the rooms table.

2.3 Database Changes

The package will create/modify the following:

New Tables

  • extra_data_in_rooms - Stores user charizma data per room

Modified Tables

  • rooms - Adds charizma_status and charizma_timestamp columns

3. Installation Steps

1 Copy the Package

Copy the Charizma folder to your project:

packages/Utd/Charizma
2 Update composer.json

Add the package path to your composer.json repositories section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/Charizma"
        }
    ]
}
3 Install the Package

Run composer require:

composer require utd/charizma
4 Run Migrations

Run migrations and clear cache:

php artisan migrate; php artisan optimize:clear

4. Configuration

4.1 Environment Variables

Add these to your .env file:

# Charizma Package Configuration
CHARIZMA_ENABLED=true

4.2 App Feature

Ensure the charizma feature is enabled in your app features:

// The routes use 'appFeatureEnable:charizma' middleware
// Make sure this feature exists in your app_features table

4.3 Publish Configuration

Publish the configuration file:

php artisan vendor:publish --tag=charizma-config

4.4 Contract Binding

The package automatically binds the following contract:

App\Contracts\UserCharismaServiceContract
→ Utd\Charizma\Services\UserCharismaService

If the package is not installed, a null implementation should be used:

App\Contracts\UserCharismaServiceContract
→ App\Services\Null\NullUserCharismaService

5. Database Tables Reference

5.1 extra_data_in_rooms

Stores user charizma/earnings data per room.

Column Type Description
id int (auto) Primary key
user_id bigint Reference to users table
room_id int Reference to rooms table
total decimal(10,2) Total earned coins/contribution
created_at timestamp Record creation time
updated_at timestamp Last update time

5.2 rooms (Modified Columns)

New columns added to the rooms table.

Column Type Description
charizma_status boolean Whether charizma is enabled for the room (default: false)
charizma_timestamp integer Timestamp when charizma was last reset (nullable)

6. Routes & API

6.1 API Routes (Mobile App)

Method URI Description
POST /api/charisma/change-status Toggle charizma status for a room
POST /api/charisma/reset Reset charizma data for a room

6.2 Middleware

All routes are protected with:

  • auth:sanctum - Authentication required
  • appFeatureEnable:charizma - Feature must be enabled
  • update.last.seen - Updates user last seen timestamp

6.3 Verify Routes

php artisan route:list | findstr charisma

7.2 Test API Endpoints

Using cURL or Postman:

# Test Change Status
curl -X POST "https://your-domain.com/api/charisma/change-status" \
  -H "Accept: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d "room_id=1&status=true"

# Test Reset Charizma
curl -X POST "https://your-domain.com/api/charisma/reset" \
  -H "Accept: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d "room_id=1"
✅ Success!

If the API returns successful responses, your installation is complete!

8. Troubleshooting

8.1 Common Issues

Issue: Route Not Found (404)

Solution: 
php artisan optimize:clear

Issue: Migration Errors (Foreign Key)

Solution:

Ensure Utd/Room package is installed and migrated first:

# Install Room package first
composer require utd/room
php artisan migrate

# Then install Charizma
composer require utd/charizma
php artisan migrate

Issue: Class Not Found Errors

Solution: 
composer dump-autoload
php artisan cache:clear

Issue: Feature Not Enabled Error

Solution:

Ensure the charizma feature is enabled in your app features table or configuration.

Issue: Contract Binding Error

Solution:

Ensure the contract exists in app/Contracts:

App\Contracts\UserCharismaServiceContract

And the null service exists:

App\Services\Null\NullUserCharismaService

8.2 Rollback Migrations

To rollback charizma migrations:

# Rollback all charizma migrations
php artisan migrate:rollback --path=packages/Utd/Charizma/Database/migrations

# Or rollback specific batch
php artisan migrate:rollback --step=1

8.3 Log Files

Check Laravel logs for detailed error information:

storage/logs/laravel.log
