✨ Charizma Package
Installation Guide

Requirements

  • PHP 8.1 or higher
  • Laravel 10.x or 11.x
  • MySQL 5.7 or higher
  • Laravel Sanctum installed
  • Utd/Room package installed (Required dependency)

Installation Steps

1 Copy the Package

Copy the Charizma folder to:

packages/Utd/Charizma
2 Update composer.json

Add this to your project's composer.json in the "repositories" section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/Charizma"
        }
    ]
}
3 Install the Package 
composer require utd/charizma
4 Run Setup Commands

Run migrations and clear cache:

php artisan migrate; php artisan optimize:clear

Verify Installation

Check if routes are registered:

php artisan route:list | findstr charisma
✅ Done! If charisma routes appear, your installation is complete.

API Endpoints

Method Endpoint Description
POST /api/charisma/change-status Toggle charizma status
POST /api/charisma/reset Reset charizma data

Configuration (Optional)

Add environment variables to your .env file:

CHARIZMA_ENABLED=true
⚠️ Important!
Make sure the Utd/Room package is installed first, as Charizma depends on it.
⚠️ Feature Flag!
Ensure the charizma feature is enabled in your app features, as routes use the appFeatureEnable:charizma middleware.
⚠️ Having Issues?
Run: 
php artisan route:list | findstr charisma
If no routes appear, contact support.
