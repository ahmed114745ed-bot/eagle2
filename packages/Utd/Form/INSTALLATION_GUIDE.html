1.3 Database Tables

The package will create the following tables:

  • form_templates - Form template definitions (multi-language)
  • form_sections - Sections within form templates
  • form_fields - Individual fields with validation rules
  • form_submissions - User form submissions
  • form_submission_values - Field values per submission
  • custom_field_widgets - Reusable custom widget components
  • form_requests - Agency/BD registration requests

2. Installation Steps

1 Copy the Package

Copy the Form folder to your project:

packages/Utd/Form
2 Update composer.json

Add the package path to your composer.json repositories section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/Form",
            "options": {
                "symlink": true
            }
        }
    ]
}

And add the package to the require section:

"utd/form": "*"
3 Install the Package

Run composer require:

composer require utd/form
4 Register in PackageHelper

Add the Form package to app/Support/PackageHelper.php:

use Utd\Form\Entities\FormTemplate;

// Add to the $packages array:
'form' => FormTemplate::class,
5 Run Migrations 
php artisan migrate
6 Run Database Seeders

Run the Form seeders to set up admin menu, widgets, and default form templates:

php artisan db:seed --class="Utd\Form\Database\Seeders\MenuFormSeeder"
php artisan db:seed --class="Utd\Form\Database\Seeders\CustomFieldWidgetSeeder"
php artisan db:seed --class="Utd\Form\Database\Seeders\AgencyAndBdFormsSeeder"
7 Update Admin Permissions

Run the permissions seeder to add Form permissions:

php artisan db:seed --class=PermissionTypeSeeder
8 Clear Cache 
php artisan cache:clear
php artisan config:clear
php artisan route:clear
php artisan view:clear

  • Turkish (tr)
  • Hindi (hi)

The package comes with 4 pre-built custom widgets:

Widget Type Purpose

Built-in data sources for select/dropdown fields:

  • cities - Cities for US, SA, EG
  • languages - 12 languages with translations

4. Database Setup

4.1 Migration Files

The package includes 15 migration files that create and update the following tables:

Migration Description
create_form_templates_table Main form template definitions
create_form_sections_table Sections within templates
create_form_fields_table Individual form fields
create_form_submissions_table Submission records
create_form_submission_values_table Field values for submissions
create_custom_field_widgets_table Custom widget definitions
add_widget_support_to_form_fields Widget FK on form_fields
add_json_support_to_form_submission_values JSON value storage
add_data_source_to_form_fields_table Data source column
add_cant_delete_table Protection flag for sections/fields
add_note_text_to_form_templates_table Note text column for templates

4.2 Seeders

Seeder Purpose
MenuFormSeeder Creates admin menu entries under Agency System
CustomFieldWidgetSeeder Creates 4 pre-built custom widgets
AgencyAndBdFormsSeeder Creates Host Agency and BD form templates

5. Routes & Middleware

5.1 Web Routes (Public)

Method URI Description
GET /forms?type=&token=&lang= Display form by type (token auth)
POST /forms/create/{type} Submit form request
GET /forms/{id} View submitted request
GET /host-agency/search Search BD/agencies

5.2 Admin Routes

Method URI Description
GET /admin/form-templates List all form templates
GET /admin/form-templates/create Create new template
GET /admin/form-templates/{id}/edit Edit template
GET /admin/form-templates/{id} Preview template
GET /admin/form-requests List form requests
POST /admin/requests/{id}/approve Approve a request
POST /admin/requests/{id}/reject Reject a request

5.3 API Routes

Method URI Description
GET /api/form-list List active forms (auth required)
GET /api/widgets List available widgets
GET /api/widgets/{id}/data Get widget data
GET /api/widgets/bd-users Get BD users
GET /api/widgets/agencies Get agencies
GET /api/data-sources/{source} Get predefined data (countries, cities, etc.)

7. Troubleshooting

7.1 Common Issues

Issue: Page Not Found (404)

Solution: 
php artisan route:clear
php artisan cache:clear
php artisan config:clear

Issue: Class Not Found Error

Solution: 
composer dump-autoload
php artisan package:discover

Issue: Admin Menu Not Showing

Solution:
  1. Run the menu seeder: php artisan db:seed --class="Utd\Form\Database\Seeders\MenuFormSeeder"
  2. Clear cache: php artisan cache:clear
  3. Check that "Agency System" parent menu exists

Issue: Form Submissions Not Saving

Solution:
  1. Check migration status: php artisan migrate:status
  2. Ensure all form tables exist in the database
  3. Verify CSRF token is included in form submissions

Issue: Translation Fields Not Working

Solution:
  1. Ensure spatie/laravel-translatable is installed
  2. Verify JSON columns in database (title, description, field_label)
  3. Check that locale is set correctly in the request

Issue: Token Authentication Failing

Solution:
  1. Verify Laravel Sanctum is properly configured
  2. Check that the token is valid and not expired
  3. Ensure the personal_access_tokens table exists

7.2 Log Files

Check Laravel logs for detailed error information:

storage/logs/laravel.log

7.3 Browser Console

Press F12 to open Developer Tools and check for JavaScript errors in the Console tab.

8. API Reference

8.1 List Forms

GET /api/form-list?type={form_type}
Authorization: Bearer {token}

Response:
{
    "status": true,
    "message": "Success",
    "data": [
        {
            "form_type": "host_agency",
            "link": "/forms?type=host_agency&token=&lang="
        }
    ]
}

8.2 Get Data Source

GET /api/data-sources/{source}?locale={locale}

Sources: countries, cities, languages, currencies

Response:
[
    {
        "value": "EG",
        "label": "Egypt"
    },
    {
        "value": "SA",
        "label": "Saudi Arabia"
    }
]

8.3 List Widgets

GET /api/widgets

Response:
[
    {
        "id": 1,
        "widget_type": "bd_selector",
        "widget_name": {"en": "BD Selector", "ar": "..."},
        "allows_multiple": true
    }
]

8.4 Get Widget Data

GET /api/widgets/{id}/data

Response:
{
    "widget": { ... },
    "data": [ ... ]
}

8.5 Submit Form Request

POST /forms/create/{type}

Body (form-data):
- user_id: int
- token: string
- agency_name / bd_name: string
- whatsapp_number: string
- bd_id: int (optional)
- country_id: int (optional)
- [dynamic fields based on form template]

Response:
{
    "success": true,
    "message": "Request under review!",
    "data": {
        "order_id": 123
    }
}

8.6 Approve Request (Admin)

POST /admin/requests/{id}/approve

Response:
{
    "success": true,
    "message": "Approved successfully"
}

8.7 Reject Request (Admin)

POST /admin/requests/{id}/reject

Response:
{
    "success": true,
    "message": "Rejected successfully",
    "icon": "success"
}

9. Supported Form Types

The package supports three specialized form types with automatic entity creation on approval:

Form Type Purpose On Approve
host_agency Host Agency registration Creates Agency record, sets user type to 2
bd_form Business Development registration Creates Bd record
shipping_agency Shipping Agency registration Creates ShippingAgency record
Important Notes
  • Each user can only own one entity of each type
  • Super admins and sub-super admins cannot register agencies
  • Duplicate submissions (same user + same form type) are prevented
