التطبيق يعمل بدون الحزمة

1

نقل مجلد الحزمة

ستقوم بنقل مجلد Reals الكامل (الذي يحتوي على composer.json و src وغيرها) إلى المسار التالي:

packages/Utd/Reals/
💡 ملاحظة: المجلد المنقول يحتوي بالفعل على composer.json - لا تحتاج لإنشائه!
📁 packages/
    📁 Utd/
        📁 Reals/ ← انقل المجلد الكامل هنا
            📄 composer.json ✓ موجود
            📄 INSTALL.html ✓ موجود
            📁 src/ ✓ موجود
            📁 routes/ ✓ موجود
            📁 resources/ ✓ موجود
2

تعديل composer.json الرئيسي

أضف الحزمة إلى ملف composer.json الرئيسي للمشروع:

composer.json

أ) أضف في قسم "require":

"utd/reals": "@dev"

ب) أضف في قسم "repositories":

{ "type": "path", "url": "packages/Utd/Reals", "options": { "symlink": true } }

ج) أضف في قسم "autoload" → "psr-4":

"Utd\\Reals\\": "packages/Utd/Reals/src/"
3

تثبيت الحزمة

قم بتنفيذ الأوامر التالية:

composer dump-autoload && php artisan optimize:clear && php artisan package:discover
✅ بعد تنفيذ هذا الأمر، ستظهر جميع حقول الريلز في التارجت وغيرها تلقائياً!
🔄

كيف يعمل النظام الديناميكي؟

المشروع يستخدم class اسمه DynamicReals في المسار:

app/Support/DynamicReals.php

هذا الـ class يفحص وجود الحزمة قبل استخدامها:

// التحقق من وجود الحزمة if (DynamicReals::isAvailable()) { // الريلز متاحة - اعرض الحقول $reelsCount = DynamicReals::queryReal()->count(); } else { // الريلز غير متاحة - لا تعرض شيء $reelsCount = 0; }
الدالة الوظيفة عند عدم وجود الحزمة
DynamicReals::isAvailable() تحقق من وجود الحزمة ترجع false
DynamicReals::queryReal() استعلام جدول الريلز ترجع null
DynamicReals::getRealClass() الحصول على class الريلز ترجع null
DynamicReals::newFfmpegService() خدمة معالجة الفيديو ترجع null
❌

ماذا يحدث عند إزالة الحزمة؟

العنصر عند وجود الحزمة ✅ عند إزالتها ❌
حقول الريلز في التارجت تظهر (upload, likes, comments) تختفي تلقائياً
نسبة الريلز في حساب الراتب تُحسب ضمن النسبة تُتجاهل (0%)
صفحة /admin/reels تعمل بشكل كامل 404 Not Found
صفحة /admin/view/reels تعمل بشكل كامل 404 Not Found
API /api/reels يعمل بشكل كامل 404 Not Found
إحصائيات المستخدم تشمل الريلز بدون ريلز
باقي التطبيق يعمل بشكل طبيعي يعمل بشكل طبيعي
✅ لا أخطاء! التطبيق يعمل بشكل طبيعي سواء كانت الحزمة موجودة أم لا.

كيفية إزالة الحزمة

لإزالة الحزمة بأمان:

# 1. أزل من composer.json: # - احذف "utd/reals": "@dev" من require # - احذف repository الخاص بالحزمة # - احذف "Utd\\Reals\\" من autoload # 2. نفذ الأوامر: composer dump-autoload && php artisan optimize:clear # 3. (اختياري) احذف مجلد الحزمة: rm -rf packages/Utd/Reals
⚠️ تنبيه: البيانات في قاعدة البيانات (جدول reels) لن تُحذف. فقط الكود سيُزال.
📚

مرجع الـ Namespaces

جميع الـ classes تستخدم namespace الجديد:

النوع Namespace
Service Provider Utd\Reals\RealsServiceProvider
Entities Utd\Reals\Entities\
Controllers Utd\Reals\Http\Controllers\
Web Controllers Utd\Reals\Http\Controllers\Web\
Services Utd\Reals\Services\
Requests Utd\Reals\Http\Requests\
Transformers Utd\Reals\Transformers\
Traits Utd\Reals\Traits\
💡 ملاحظة: الـ namespace القديم Modules\Reals\ لا يزال مدعوماً كـ fallback في DynamicReals

الأوامر السريعة

تثبيت الحزمة:

composer dump-autoload && php artisan optimize:clear && php artisan package:discover

التحقق من التثبيت:

php artisan tinker --execute="echo Utd\Reals\Entities\Real::count();"

مسح الكاش بالكامل:

php artisan cache:clear && php artisan config:clear && php artisan route:clear && php artisan view:clear && composer dump-autoload
