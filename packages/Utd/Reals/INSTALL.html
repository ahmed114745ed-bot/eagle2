🎬 تثبيت حزمة Utd/Reals

1

نقل مجلد الحزمة

ستقوم بنقل مجلد Reals الكامل (الذي يحتوي على composer.json و src وغيرها) إلى المسار التالي:

packages/Utd/Reals/
💡 ملاحظة: المجلد المنقول يحتوي بالفعل على composer.json - لا تحتاج لإنشائه!
📁 packages/
    📁 Utd/
        📁 Reals/ ← انقل المجلد الكامل هنا
            📄 composer.json ✓ موجود
            📄 INSTALL.html ✓ موجود
            📁 src/ ✓ موجود
            📁 routes/ ✓ موجود
            📁 resources/ ✓ موجود
2

تعديل composer.json الرئيسي

أضف الحزمة إلى ملف composer.json الرئيسي للمشروع:

composer.json

أ) أضف في قسم "require":

"utd/reals": "@dev"

ب) أضف في قسم "repositories":

{ "type": "path", "url": "packages/Utd/Reals", "options": { "symlink": true } }

ج) أضف في قسم "autoload" → "psr-4":

"Utd\\Reals\\": "packages/Utd/Reals/src/"
✅ ملاحظة هامة: المشروع يستخدم RealsPackageServiceProvider الذي يتحقق تلقائياً من وجود الحزمة. لا تحتاج لتعديل config/app.php - الحزمة ستُكتشف تلقائياً!
3

تثبيت الحزمة

قم بتنفيذ الأوامر التالية:

composer dump-autoload && php artisan optimize:clear && php artisan package:discover

ثم قم بتشغيل أمر التثبيت:

php artisan reals:install
💡 ملاحظة: أمر التثبيت يقوم بـ:
  • إنشاء جميع الجداول المطلوبة
  • إضافة الأعمدة للجداول المشتركة (مثل users)
  • نشر الـ assets للمجلد public
✅ بعد تنفيذ هذا الأمر، ستظهر جميع حقول الريلز في التارجت وغيرها تلقائياً!
4

تشغيل الـ Seeders

قم بتشغيل الـ seeders لإعداد قوائم الأدمن:

php artisan db:seed --class=Utd\\Reals\\Database\\Seeders\\RealDatabaseSeeder

ثم قم بتحديث الصلاحيات:

php artisan db:seed --class=PermissionTypeSeeder
💡 ملاحظة: الـ seeders تقوم بـ:
  • إضافة قوائم الريلز في لوحة التحكم
  • إضافة صلاحيات إدارة الريلز للمشرفين
🗄️

الجدول الوصف النوع

كيفية إزالة الحزمة

لإزالة الحزمة بأمان:

الطريقة 1: استخدام الأمر (مُوصى به):

# إلغاء التثبيت مع حذف جميع البيانات: php artisan reals:uninstall # إلغاء التثبيت مع الاحتفاظ بالجداول (حذف الأعمدة المشتركة فقط): php artisan reals:uninstall --keep-data # إلغاء التثبيت بدون تأكيد: php artisan reals:uninstall --force
⚠️ تحذير: أمر reals:uninstall سيحذف:
  • جميع جداول الريلز وبياناتها
  • عمود reel_following_type من جدول users
  • سجلات الـ migrations من جدول migrations
  • مجلد public/modules/reals

الطريقة 2: الإزالة اليدوية:

# 1. أزل من composer.json: # - احذف "utd/reals": "@dev" من require # - احذف repository الخاص بالحزمة # - احذف "Utd\\Reals\\" من autoload # 2. نفذ الأوامر: composer dump-autoload && php artisan optimize:clear # 3. (اختياري) احذف مجلد الحزمة: rm -rf packages/Utd/Reals
⚠️ تنبيه: الإزالة اليدوية لا تحذف البيانات من قاعدة البيانات. استخدم الأمر للإزالة الكاملة.
⚡

الأوامر السريعة

تثبيت الحزمة:

composer dump-autoload && php artisan optimize:clear && php artisan package:discover && php artisan reals:install

إلغاء تثبيت الحزمة:

php artisan reals:uninstall --force

التحقق من التثبيت:

php artisan tinker --execute="echo Utd\Reals\Entities\Real::count();"

مسح الكاش بالكامل:

php artisan cache:clear && php artisan config:clear && php artisan route:clear && php artisan view:clear && composer dump-autoload
