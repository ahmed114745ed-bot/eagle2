1. Overview

1.1 What is Milestones?

The Milestones package is a reward management system that allows granting milestone-based rewards to users based on their roles and achievements. It provides an admin panel for managing milestones and their associated rewards (VIPs, badges, wares, coins, etc.).

1.2 Key Features

  • Milestone Management - Create and manage milestones with slugs for programmatic access
  • Reward System - Associate multiple rewards (VIP, Badge, Ware, Achievement, Coins) with each milestone
  • Auto-Grant Rewards - Automatically grant rewards to users when they achieve a milestone
  • Auto-Remove Rewards - Remove milestone rewards when a user loses their role/status
  • Sync Functionality - Sync milestone rewards to all eligible users at once
  • History Tracking - Track reward history via the v_user_history_rewards database view
  • Contract-Based Architecture - Uses contracts for loose coupling; falls back to null implementation when package is not installed

1.3 How It Works

  1. Admin creates a milestone (e.g., "host", "super-admin", "bd") in the admin panel
  2. Admin assigns rewards to the milestone (VIP packages, badges, wares, etc.)
  3. When a user achieves the milestone (e.g., becomes a host), the system calls grantMilestoneToUser()
  4. All rewards associated with that milestone are automatically granted to the user
  5. When the user loses the role, removeReward() is called to revoke the rewards

3. Installation Steps

1 Copy the Package

Copy the Milestones folder to your project:

packages/Utd/Milestones
2 Update composer.json

Add the package path to your composer.json repositories section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/Milestones"
        }
    ]
}
3 Install the Package

Run composer require:

composer require utd/milestones
4 Run Migrations

Run migrations to create database tables and views:

php artisan migrate
5 Clear Cache

Clear the application cache:

php artisan optimize:clear
Note

The package automatically registers its service provider via Laravel's package discovery. The MilestoneHelperContract binding will override the null fallback registered in FeatureServiceProvider.

4. Configuration

4.1 Publish Configuration

Publish the configuration file:

php artisan vendor:publish --tag=config

This publishes to config/milestones.php.

4.2 Configuration Options

// config/milestones.php
return [
    'name' => 'Milestones'
];

4.3 Dependency Injection

The package registers MilestoneHelperContract which can be used via the container:

// Using the contract via app() helper
app(\App\Contracts\MilestoneHelperContract::class)
    ->grantMilestoneToUser($user, 'host');

// Removing rewards
app(\App\Contracts\MilestoneHelperContract::class)
    ->removeReward($user, 'host');
Fallback Behavior

If the Milestones package is not installed, the application uses NullMilestoneHelperService as a fallback. All methods return gracefully without errors — grantMilestoneToUser() and removeReward() simply do nothing.

5.3 v_user_history_rewards (Database View)

A database view that joins user_history_rewards with milestones, admin_roles, wares, o_vips, and badges tables for comprehensive reward history tracking.

Column Source Description
receive_category Computed "Role" or "Milestone"
receive_name Joined Name from admin_roles or milestones table
reward_name Joined Name from wares, o_vips, or badges table
reward_img Joined Image from the reward item

7. Architecture & Contracts

7.1 Contract Pattern

The package uses a contract-based architecture for loose coupling:

Contract (in main app)

// app/Contracts/MilestoneHelperContract.php
interface MilestoneHelperContract
{
    public function grantMilestoneToUser($user, string $slug): void;
    public function removeReward($user, string $slug): void;
}

Null Implementation (fallback)

// app/Services/Null/NullMilestoneHelperService.php
class NullMilestoneHelperService implements MilestoneHelperContract
{
    public function grantMilestoneToUser($user, string $slug): void {}
    public function removeReward($user, string $slug): void {}
}

Real Implementation (in package)

// packages/Utd/Milestones/src/Services/MilestoneHelperService.php
class MilestoneHelperService implements MilestoneHelperContract
{
    // Delegates to MilestoneHelper static methods
}

7.2 Binding Order

  1. FeatureServiceProvider registers NullMilestoneHelperService as default
  2. If package is installed, MilestonesServiceProvider overrides with MilestoneHelperService

7.3 Usage in Code

// Always safe to call - uses null fallback if package not installed
app(\App\Contracts\MilestoneHelperContract::class)
    ->grantMilestoneToUser($user, 'host');

app(\App\Contracts\MilestoneHelperContract::class)
    ->removeReward($user, 'host');

9. Troubleshooting

9.1 Common Issues

Package Not Found

Error: Package utd/milestones not found

Ensure the package path is correctly added to composer.json repositories and run composer update.

Migration Errors

Error: View creation fails

The view migrations check for required tables (admin_roles, milestones, user_history_rewards) before creating. Ensure these tables exist.

Contract Not Resolving

Error: NullMilestoneHelperService is being used instead of real service

Ensure the package is properly installed and MilestonesServiceProvider is registered. Run php artisan package:discover.

Admin Routes Not Showing

Error: 404 on milestone admin routes

Clear route cache: php artisan route:clear and verify the admin prefix in your config/admin.php.
