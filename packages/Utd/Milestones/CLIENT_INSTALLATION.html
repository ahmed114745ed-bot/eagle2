🏆 Milestones Package
Installation Guide

Requirements

  • PHP 8.1 or higher
  • Laravel 10.x or 11.x
  • MySQL 5.7 or higher
  • Laravel Admin (Encore) installed

Installation Steps

1 Copy the Package

Copy the Milestones folder to:

packages/Utd/Milestones
2 Update composer.json

Add this to your project's composer.json in the "repositories" section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/Milestones"
        }
    ]
}
3 Install the Package 
composer require utd/milestones
4 Run Migrations, Seeders & Clear Cache 
php artisan migrate; php artisan db:seed --class="Utd\Milestones\Database\Seeders\MilestonesDatabaseSeeder"; php artisan db:seed --class="Database\Seeders\PermissionTypeSeeder"; php artisan optimize:clear

Verify Installation

Check if routes are registered:

php artisan route:list | findstr milestones

Check contract binding:

php artisan tinker
>>> app(\App\Contracts\MilestoneHelperContract::class)

Should return: Utd\Milestones\Services\MilestoneHelperService

✅ Done! If milestone routes appear and the contract resolves to MilestoneHelperService, your installation is complete.

Admin Panel Routes

Milestones Management

Method Endpoint Description
GET /{admin}/milestones List all milestones
GET /{admin}/milestones/create Create milestone form
POST /{admin}/milestones Store new milestone
GET /{admin}/milestones/{id}/edit Edit milestone
PUT /{admin}/milestones/{id} Update milestone
DELETE /{admin}/milestones/{id} Delete milestone
GET /{admin}/milestones/{id}/sync Sync rewards to eligible users

Milestone Rewards

Method Endpoint Description
GET /{admin}/milestone-rewards/{milestone_id} List rewards for milestone
GET /{admin}/milestone-rewards/{milestone_id}/create Create reward form
POST /{admin}/milestone-rewards/{milestone_id} Store new reward
PUT /{admin}/milestone-rewards/{milestone_id}/{id} Update reward
DELETE /{admin}/milestone-rewards/{milestone_id}/{id} Delete reward

Database Tables

Table Description
milestones Main milestones (name, slug, description, is_active)
milestone_rewards Rewards linked to milestones (polymorphic: VIP, Badge, Ware, etc.)
v_user_history_rewards Database view for reward history tracking

Usage

Grant milestone rewards to a user:

app(\App\Contracts\MilestoneHelperContract::class)
    ->grantMilestoneToUser($user, 'host');

Remove milestone rewards from a user:

app(\App\Contracts\MilestoneHelperContract::class)
    ->removeReward($user, 'host');

Uninstall

php artisan migrate:rollback --path=packages/Utd/Milestones/Database/Migrations
⚠️ Having Issues?
Make sure Laravel Admin (Encore) is installed.
Run: 
php artisan route:list | findstr milestones
If no routes appear, try: php artisan optimize:clear
If still not working, contact support.
