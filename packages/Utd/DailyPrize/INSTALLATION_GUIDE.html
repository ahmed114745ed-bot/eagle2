2. Installation Steps

1 Copy the Package

Copy the DailyPrize folder to your project:

packages/Utd/DailyPrize
2 Update composer.json

Add the package path to your composer.json repositories section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/DailyPrize"
        }
    ],
    "require": {
        "utd/daily-prize": "*"
    }
}
3 Install the Package 
composer require utd/daily-prize
4 Run Setup Commands

Run migrations, seed menu & permissions, and clear cache (all in one command):

php artisan migrate; php artisan db:seed --class="Utd\DailyPrize\Database\Seeders\DailyPrizeDatabaseSeeder"; php artisan db:seed --class=PermissionTypeSeeder; php artisan optimize:clear
