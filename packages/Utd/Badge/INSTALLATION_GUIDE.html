1. Overview

1.1 What is Badge?

The Badge package provides a complete badge management system for users. It allows administrators to create, manage, and dedicate badges to users with expiration support and multi-language image capabilities.

1.2 Key Features

  • Badge Management - Create and manage badges with priority ordering
  • Multi-language Images - Support for badge images in different languages with fallback
  • Badge Types - Support for "top" and "regular" badge types
  • Badge Dedication - Dedicate badges to users with configurable expiration (days)
  • User Badge History - Track all badge assignments with admin panel views
  • Image Types - Support for SVGA, Alpha, VAP, and standard image formats
  • Admin Panel Integration - Full Laravel-Admin (Encore) integration for management

1.3 How It Works

  1. Admin creates badges with names, types, priorities, and multi-language images
  2. Admin dedicates badges to users by UUID with a specified number of days
  3. Users receive badges that appear in their profile via the API
  4. Badges automatically expire based on the configured duration
  5. API returns badges grouped by type (top/regular) with language-aware images

3. Installation Steps

1 Copy the Package

Copy the Badge folder to your project:

packages/Utd/Badge
2 Update composer.json

Add the package path to your composer.json repositories section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/Badge"
        }
    ]
}
3 Install the Package

Run composer require:

composer require utd/badge
4 Run Migrations & Seeders

Run migrations to create database tables, then run the permission type seeder and badge seeder:

php artisan migrate; php artisan db:seed --class=PermissionTypeSeeder; php artisan db:seed --class=Utd\Badge\Database\Seeders\BadgeDatabaseSeeder
5 Clear Cache

Clear the application cache:

php artisan optimize:clear
Note

The PermissionTypeSeeder will create the necessary admin permissions for badge management (badges, dedicate-badges). Make sure to run it to enable admin panel access.

4. Configuration

4.1 Publish Configuration

Publish the configuration file (optional):

php artisan vendor:publish --tag=config

4.2 Admin Permissions

The package registers the following admin permissions:

Permission Key Description Methods
badges Manage badges (CRUD) browse, read, edit, add, delete
dedicate-badges Dedicate badges to users browse, dedicate-switch
dedicate-user-badges View user badge history browse

4.3 PackageHelper Integration

The package is automatically detected by PackageHelper::isInstalled('badge'). External code that references Badge entities should use this check:

if (PackageHelper::isInstalled('badge')) {
    // Badge-related code
}

5. Database Tables Reference

5.1 badges

Column Type Description
id bigint Primary key
name string (unique) Badge name
image string (nullable) Default badge image path
show_image string (nullable) Display image path
image_type string (nullable) Image type (svga, alpha, vap, image)

6. Routes & API

6.1 API Routes

Base URL: /api

Middleware: auth:sanctum, update.last.seen

Method Endpoint Description
GET /api/badges/users/{id} Get user badges (grouped by top/regular)

6.2 Admin Web Routes

Base URL: /admin

Middleware: web, admin, adminIp, multiLanguage, appFeatureEnable:achievement

Method Endpoint Description
GET /admin/badges List all badges
GET /admin/badges/create Create badge form
POST /admin/badges Store new badge
GET /admin/badges/{id} Show badge details
GET /admin/badges/{id}/edit Edit badge form
PUT /admin/badges/{id} Update badge
DELETE /admin/badges/{id} Delete badge
GET /admin/dedicate-badges Dedicate badges to users
GET /admin/user-badges View user badge history

Test the user badges endpoint (requires authentication):

curl -X GET "https://your-domain.com/api/badges/users/1" \
  -H "Authorization: Bearer YOUR_TOKEN"
Success! If all checks pass, the Badge package is properly installed and configured.

8. Troubleshooting

8.1 Common Issues

Package Not Found

Error: Package utd/badge not found

Ensure the package path is correctly added to composer.json repositories and run composer update.

Migration Errors

Error: Table already exists

If the badges table already exists from a previous module installation, the migration will handle it. Check if you need to run only the new migrations.

Admin Permissions Not Showing

Error: Badge menu not visible in admin

Run the permission seeder: php artisan db:seed --class=PermissionTypeSeeder and assign the badge permissions to your admin role.

Route Not Found

Error: 404 on badge routes

Clear route cache: php artisan route:clear and verify the service provider is registered.

8.2 Useful Commands
