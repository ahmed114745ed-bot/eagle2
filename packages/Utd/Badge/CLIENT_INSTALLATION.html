🏅 Badge Package
Installation Guide

Requirements

  • PHP 8.1 or higher
  • Laravel 10.x or 11.x
  • MySQL 5.7 or higher
  • Laravel Sanctum installed
  • Laravel-Admin (Encore) installed

Installation Steps

1 Copy the Package

Copy the Badge folder to:

packages/Utd/Badge
2 Update composer.json

Add this to your project's composer.json in the "repositories" section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/Badge"
        }
    ]
}
3 Install the Package 
composer require utd/badge
4 Run Migrations & Seeders 
php artisan migrate; php artisan db:seed --class=PermissionTypeSeeder; php artisan db:seed --class=Utd\\Badge\\Database\\Seeders\\BadgeDatabaseSeeder; php artisan optimize:clear

Verify Installation

Check if routes are registered:

php artisan route:list | findstr badges
✅ Done! If badge routes appear, your installation is complete.

API Endpoints

Method Endpoint Description
GET /api/badges/users/{id} Get user badges (top & regular)

Admin Panel Routes

URL Description
/admin/badges Manage badges (CRUD)
/admin/dedicate-badges Dedicate badges to users
/admin/user-badges View user badge history

Database Tables

Table Description
badges Badge definitions (name, type, priority)
user_badges User-badge assignments with expiration
badge_images Multi-language badge images

Uninstall

php artisan migrate:rollback --path=packages/Utd/Badge/Database/Migrations
⚠️ Having Issues?
Make sure to run the PermissionTypeSeeder for admin access.
Run: 
php artisan route:list | findstr badges
If no routes appear, try: php artisan optimize:clear
