📸 Moments Package
Installation Guide

Requirements

  • PHP 8.1 or higher
  • Laravel 10.x or 11.x
  • MySQL 5.7 or higher
  • Laravel-Admin package installed

Installation Steps

1 Copy the Package

Copy the Moments folder to:

packages/Utd/Moments
2 Update composer.json

Add this to your project's composer.json in the "repositories" section:

{ "type": "path", "url": "packages/Utd/Moments" }
3 Install the Package composer require utd/moments
4 Publish Configuration php artisan vendor:publish --tag=moments
5 Run Database Migrations php artisan migrate
6 Clear Cache php artisan cache:clear php artisan config:clear php artisan route:clear
7 Create Storage Link php artisan storage:link
8 Setup Admin Permissions

Run the permission seeder to add Moments permissions to admin panel:

php artisan db:seed --class=AdminPermissionRefact

Verify Installation

Open your browser and go to:

https://your-domain.com/admin/moment-viewer
✅ Done! If the page loads, your installation is complete.

Configuration (Optional)

Add these to your .env file:

MOMENT_VIEWER_PER_PAGE=12 MOMENT_VIEWER_DEFAULT_SORT=random
⚠️ Having Issues?
Run: php artisan route:list | grep moment If no routes appear, contact support.
