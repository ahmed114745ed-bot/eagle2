The package will create the following tables:

  • moment - Main moments table
  • moment_user_likes - Likes tracking
  • moment_user_comments - Comments storage
  • moment_user_gifts - Gifts tracking
  • moment_gallery - Media/Gallery storage

2. Installation Steps

1 Copy the Package

Copy the Moments folder to your project:

packages/Utd/Moments
2 Update composer.json

Add the package path to your composer.json repositories section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/Moments"
        }
    ]
}
3 Install the Package

Run composer require:

composer require utd/moments
4 Publish Configuration Files 
php artisan vendor:publish --tag=moments

This will publish:

  • config/moments.php - Main configuration
  • config/moments-viewer.php - Viewer configuration
  • Database migrations
5 Run Migrations 
php artisan migrate
6 Setup Admin Permissions

Run the permission seeder to add Moments permissions to admin panel:

php artisan db:seed --class=AdminPermissionRefact
7 Clear Cache 
php artisan cache:clear
php artisan config:clear
php artisan route:clear
php artisan view:clear
8 Create Storage Link (if not exists) 
php artisan storage:link

3. Configuration

3.1 Environment Variables

Add these to your .env file:

# Moments Package Configuration
MOMENTS_LICENSE_KEY=your_license_key
MOMENTS_LICENSE_SECRET=moments-secret-key

# Moment Viewer Configuration
MOMENT_VIEWER_PER_PAGE=12
MOMENT_VIEWER_DEFAULT_SORT=random

3.2 Main Configuration (config/moments.php)

<?php

return [
    'name' => 'Moments',
    
    // License key for the package
    'license_key' => env('MOMENTS_LICENSE_KEY', ''),
    'license_secret' => env('MOMENTS_LICENSE_SECRET', 'moments-secret-key'),
    
    // Default moment privacy setting
    'default_privacy' => 'public',
    
    // Maximum file size for uploads (in KB)
    'max_file_size' => 10240,
    
    // Allowed file types
    'allowed_file_types' => [
        'image/jpeg', 
        'image/png', 
        'image/gif', 
        'video/mp4'
    ],
    
    // Enable/disable features
    'comments_enabled' => true,
    'likes_enabled' => true,
];

3.3 Viewer Configuration (config/moments-viewer.php)

<?php

return [
    'theme' => [
        'app_name' => 'Moments Viewer',
    ],
    
    // Items per page
    'per_page' => env('MOMENT_VIEWER_PER_PAGE', 12),
    
    // Default sort order: random, newest, oldest
    'default_sort' => env('MOMENT_VIEWER_DEFAULT_SORT', 'random'),
    
    // Feature toggles
    'features' => [
        'likes' => true,
        'comments' => true,
        'gifts' => true,
        'delete_moment' => true,
        'delete_comment' => true,
        'navigation' => true,
    ],
    
    // Media settings
    'media' => [
        'max_display_items' => 10,
        'default_avatar' => 'images/businessman-icon.jpg',
    ],
    
    // Pagination options
    'pagination' => [
        'per_page_options' => [12, 24, 36, 48],
        'show_page_info' => true,
    ],
    
    // Random sorting settings
    'random' => [
        'session_based' => true,
        'seed_lifetime' => 3600,
    ],
    
    // Cache settings (optional)
    'cache' => [
        'enabled' => false,
        'ttl' => 300,
    ],
];

4. Database Setup

4.1 Migration Files

The package includes the following migrations:

Migration Description
add_moment_table Creates main moment table
add_moment_user_likes_table Creates likes tracking table
add_moment_user_comments_table Creates comments table
create_moment_user_gifts_table Creates gifts tracking table
create_moment_galleries_table Creates media gallery table

4.2 Database Indexing (Recommended)

For better performance, add these indexes:

-- Add indexes for better query performance
ALTER TABLE moment ADD INDEX idx_user_id (user_id);
ALTER TABLE moment ADD INDEX idx_created_at (created_at);
ALTER TABLE moment ADD INDEX idx_user_created (user_id, created_at);
ALTER TABLE moment_user_likes ADD INDEX idx_moment_id (moment_id);
ALTER TABLE moment_user_comments ADD INDEX idx_moment_id (moment_id);

4.3 Seeding Test Data (Optional)

php artisan db:seed --class=Utd\\Moments\\Database\\Seeders\\MomentSeeder

5. Routes & Middleware

5.1 Available Routes

The package registers the following routes:

Web Routes (Admin Panel)

Method URI Description
GET /admin/moment-viewer Viewer index page
GET /admin/moment-viewer/api/moments List moments (paginated)
GET /admin/moment-viewer/api/moment/{id} Get single moment
GET /admin/moment-viewer/api/moment/{id}/likes Get moment likes
GET /admin/moment-viewer/api/moment/{id}/comments Get moment comments
GET /admin/moment-viewer/api/moment/{id}/gifts Get moment gifts
PUT /admin/moment-viewer/api/moment/{id}/description Update description
DELETE /admin/moment-viewer/api/moment/{id} Delete moment
DELETE /admin/moment-viewer/api/comment/{id} Delete comment

API Routes

Method URI Description
GET /api/Utd/moments List moments
GET /api/Utd/moments/{id} Get moment details
POST /api/Utd/moments Create moment
POST /api/Utd/moments/{id}/like Like/Unlike moment
POST /api/Utd/moments/{id}/comment Add comment

5.2 Middleware Setup

The package registers moment.allowed middleware automatically.

📝 Note

If you need to customize the middleware, create your own in app/Http/Middleware/ and register it in app/Http/Kernel.php:

// app/Http/Kernel.php
protected $routeMiddleware = [
    // ...
    'moment.allowed' => \App\Http\Middleware\MomentAllowed::class,
];

5.3 Verify Routes

php artisan route:list | findstr moment-viewer

7. Troubleshooting

7.1 Common Issues

Issue: Page Not Found (404)

Solution: 
php artisan route:clear
php artisan cache:clear
php artisan config:clear

Issue: Route Not Defined Error

Solution:

Clear route cache and verify routes are registered:

php artisan route:clear
php artisan route:list | findstr moment

Issue: Images Not Displaying

Solution:
  1. Verify storage link exists: php artisan storage:link
  2. Check file permissions on storage folder
  3. Verify getImagePath() helper function exists

Issue: CSRF Token Mismatch

Solution: 
php artisan config:clear
php artisan cache:clear

Ensure this meta tag exists in your layout:

<meta name="csrf-token" content="{{ csrf_token() }}">

Issue: Middleware Not Found

Solution:

Verify middleware is registered in app/Http/Kernel.php:

protected $routeMiddleware = [
    'moment.allowed' => \Utd\Moments\Http\Middleware\CheckAllowedMoment::class,
];

Issue: Database Query Errors

Solution:
  1. Run migrations: php artisan migrate
  2. Check table structure matches model relationships
  3. Verify foreign keys are properly set

7.2 Log Files

Check Laravel logs for detailed error information:

storage/logs/laravel.log

7.3 Browser Console

Press F12 to open Developer Tools and check for JavaScript errors in the Console tab.

8. API Reference

8.1 List Moments

GET /admin/moment-viewer/api/moments

Parameters:
- page (int): Page number
- per_page (int): Items per page (default: 12)
- sort (string): Sorting method (random, newest, oldest)
- user_id (int): Filter by user ID

Response:
{
    "data": [...],
    "current_page": 1,
    "last_page": 10,
    "per_page": 12,
    "total": 120
}

8.2 Get Moment Details

GET /admin/moment-viewer/api/moment/{id}

Response:
{
    "id": 1,
    "user_id": 123,
    "description": "...",
    "media": [...],
    "likes_count": 50,
    "comments_count": 10,
    "created_at": "2026-01-21T10:00:00Z"
