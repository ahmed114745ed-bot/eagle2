Overview

The Events package provides a comprehensive event management system including Weekly Star events, Charging Events, PK Events, and General Roles. It allows administrators to create and manage various types of events with rewards, winners, and gift configurations.

Laravel10.x or 11.x

Installation

Step 1: Copy Package

Copy the Events folder to your packages directory:

packages/Utd/Events
Step 2: Update composer.json

Add the repository and require the package:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/Events",
            "options": {
                "symlink": true
            }
        }
    ],
    "require": {
        "utd/events": "*"
    }
}
Step 3: Install via Composer
composer update utd/events
Step 4: Run Migrations
php artisan migrate
Step 5: Run Seeders
php artisan db:seed --class=PermissionTypeSeeder; php artisan db:seed --class="Utd\Events\Database\Seeders\EventsDatabaseSeeder"
Step 6: Clear Cache
php artisan optimize:clear
✅ Installation Complete!
The package is now installed and ready to use.

Contracts & Integration

The Events package exposes contracts for external integration. When the package is not installed, null implementations are automatically used.

Available Contracts

ContractDescription
LoseWinnerRewardsContractService for handling winner reward removal

Usage Example

use App\Contracts\LoseWinnerRewardsContract;

// Get service (returns null implementation if package not installed)
$service = app(LoseWinnerRewardsContract::class);

// Remove VIP packs from users who lost
$service->removePacksVip($losingUserIds);
📘 Note:
Use PackageHelper::isInstalled('event') to check if the Events package is installed before showing event-related UI elements.

Package Removal

⚠️ Warning: Removing this package will affect event functionality. Ensure fallback contracts are properly configured.
Step 1: Remove Package
composer remove utd/events
Step 2: Rollback Migrations (Optional)
php artisan migrate:rollback --path=packages/Utd/Events/Database/Migrations --step=20
Step 3: Remove Repository Entry

Remove the Events repository entry from composer.json.

Step 4: Delete Package Folder
rm -rf packages/Utd/Events
Step 5: Clear Cache
php artisan optimize:clear
📘 Note:
After removal, the application will automatically use null implementations for Events contracts, ensuring no errors occur.
