UTD Gifts Package | Laravel 10+

📋 المتطلبات

  • PHP: 8.1+

🚀 خطوات التثبيت

1 إضافة الباكيج إلى composer.json

افتح ملف composer.json في جذر المشروع

⚠️ ملاحظة: أضف هذه الأسطر داخل الملف الموجود، لا تحذف المحتوى القديم

أولاً: أضف في قسم "repositories":

"repositories": [ { "type": "path", "url": "./packages/Utd/Gifts" } ]

ثانياً: أضف في قسم "require":

"require": { "utd/gifts": "*" }

مثال: الشكل النهائي الكامل

{ "name": "your-project", "repositories": [ { "type": "path", "url": "./packages/Utd/Gifts" } ], "require": { "php": "^8.1", "laravel/framework": "^10.0", "utd/gifts": "*" } }
2 تثبيت الباكيج
composer update utd/gifts
3 نشر ملف Config
php artisan vendor:publish --tag=gifts-config
4 تشغيل الـ Migrations
php artisan migrate
✅ سيتم إنشاء الجداول تلقائياً!
5 تنظيف الـ Cache وإعادة التشغيل
php artisan config:clear php artisan cache:clear

✅ اختبار التثبيت

افتح المتصفح:

http://your-domain.com/admin/gifts
🎉 إذا ظهرت صفحة الهدايا، التثبيت تم بنجاح!
