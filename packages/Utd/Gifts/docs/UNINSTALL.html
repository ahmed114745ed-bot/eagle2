🗑️ إلغاء تثبيت حزمة الهدايا

Uninstall Gifts Package

⚠️ ملاحظة هامة

إلغاء التثبيت سيؤدي إلى:

  • ❌ إزالة ملفات الحزمة من المشروع
  • ❌ توقف جميع الوظائف المتعلقة بالهدايا
  • ✅ البيانات في قاعدة البيانات ستبقى محفوظة
  • ✅ صور الهدايا ستبقى في مكانها

💡 البيانات لن تُحذف تلقائياً - يمكنك حذفها يدوياً إذا أردت

📦 النسخ الاحتياطي (اختياري)

1. نسخ احتياطي لقاعدة البيانات (إذا أردت)

إذا كنت تريد نسخ البيانات قبل الحذف:

# نسخ الجداول الخاصة بالهدايا mysqldump -u username -p database_name \ gifts \ gift_categories \ gift_logs \ user_gifts \ lucky_gifts \ > gifts_backup_$(date +%Y%m%d).sql

2. نسخ ملفات الصور (إذا أردت)

# نسخ صور الهدايا cp -r public/storage/gifts ~/backup/gifts_images_$(date +%Y%m%d)

🗑️ خطوات إلغاء التثبيت

الخطوة 1: حذف من composer.json

افتح ملف composer.json واحذف السطور التالية:

من قسم repositories:

{ "type": "path", "url": "./packages/Utd/Gifts" }

من قسم require:

"utd/gifts": "*"

الخطوة 2: تحديث Composer

composer update utd/gifts --with-all-dependencies

💡 ملاحظة

سيقوم Composer بإزالة الحزمة وكل dependencies الخاصة بها

البيانات في قاعدة البيانات لن تُحذف

الخطوة 3: حذف ملف الإعدادات

rm config/gifts.php

الخطوة 4: حذف الـ Class Aliases (إذا كانت موجودة)

احذف الملفات التالية إذا كانت موجودة:

rm app/Models/Gift.php rm app/Models/GiftLog.php rm app/Models/GiftCategory.php rm app/Models/UserGift.php rm app/Models/LuckyGift.php rm app/Observers/GiftCategoryObserver.php

الخطوة 6: حذف مجلد الباكيج

rm -rf packages/Utd/Gifts

الخطوة 7: تنظيف الملفات المؤقتة

composer dump-autoload php artisan config:clear php artisan cache:clear php artisan route:clear php artisan view:clear

الخطوة 5: حذف مجلد الحزمة

rm -rf packages/Utd/Gifts

🗄️ حذف قاعدة البيانات (اختياري)

⚠️ تحذير: هذا الخطوة اختيارية وخطيرة!

لا تنفذ هذه الخطوة إلا إذا كنت متأكداً أنك لا تحتاج البيانات!

سيتم حذف جميع سجلات الهدايا بشكل نهائي ولا يمكن استرجاعها!

إذا أردت حذف جداول قاعدة البيانات:

أ) الطريقة الآمنة (عبر Laravel):

php artisan migrate:rollback --path=packages/Utd/Gifts/database/migrations

ب) الطريقة المباشرة (SQL):

DROP TABLE IF EXISTS `gift_logs`; DROP TABLE IF EXISTS `user_gifts`; DROP TABLE IF EXISTS `lucky_gifts`; DROP TABLE IF EXISTS `gifts`; DROP TABLE IF EXISTS `gift_categories`;

حذف صور الهدايا (اختياري)

⚠️ تحذير

تأكد من نسخ الصور قبل الحذف إذا كنت تحتاجها

rm -rf public/storage/gifts rm -rf storage/app/public/gifts

✨ لا حاجة لتعديل الكود!

النظام مصمم ليكون fail-safe:

  • ✅ الباكيجات الأخرى تستخدم Contracts وليس الحزمة مباشرة
  • ✅ FeatureServiceProvider يوفر Null implementations تلقائياً
  • ✅ لو تم حذف الحزمة، التطبيق يشتغل عادي مع Null implementations
  • ✅ لا توجد أخطاء أو crashes - فقط الميزات تتوقف

💡 يمكنك حذف الحزمة مباشرة بدون تعديل أي كود!

✅ التحقق من الإلغاء

قائمة التحقق النهائية

  • تم حذف الحزمة من composer.json
  • تم تشغيل composer update بنجاح
  • تم حذف ملف config/gifts.php
  • تم حذف Class Aliases من app/Models (إذا كانت موجودة)
  • تم حذف مجلد packages/Utd/Gifts
  • تم مسح جميع أنواع الكاش
  • لا توجد أخطاء عند تشغيل التطبيق
  • البيانات في قاعدة البيانات لا تزال موجودة (ما لم تحذفها يدوياً)

اختبار نهائي

# تأكد من عدم وجود أخطاء php artisan config:cache php artisan optimize:clear # اختبار التطبيق php artisan serve

🔄 استعادة البيانات (إذا لزم الأمر)

استرجاع من النسخة الاحتياطية

# استرجاع قاعدة البيانات mysql -u username -p database_name < gifts_backup_20260204.sql # استرجاع الصور cp -r ~/backup/gifts_images_20260204/* public/storage/gifts/ # إعادة التثبيت composer require utd/gifts php artisan migrate php artisan config:cache

❗ المشاكل الشائعة

مشكلة: Class not found بعد الإلغاء

الحل:

composer dump-autoload php artisan config:clear php artisan cache:clear

مشكلة: أريد حذف بيانات قاعدة البيانات

الحل:

راجع القسم "🗄️ حذف قاعدة البيانات (اختياري)" في الأعلى

# إذا أردت حذفها يدوياً DROP TABLE IF EXISTS gift_logs; DROP TABLE IF EXISTS gifts;

مشكلة: قوائم الهدايا لا تزال ظاهرة

الحل:

php artisan cache:clear php artisan view:clear php artisan config:clear
