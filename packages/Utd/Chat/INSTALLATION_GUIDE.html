1. Overview

1.1 What is Chat?

Chat is a real-time messaging package that provides private messaging between users and group chat (world chat) functionality. It supports text messages, images, audio, video, and various message types with real-time delivery via Pusher.

1.2 Key Features

  • Private Chat - One-on-one messaging between users
  • Group Chat (World Chat) - Public messaging visible to all users
  • Real-time Messaging - Instant message delivery via Pusher
  • Message Types - Text, image, audio, video, gift, CP requests
  • Message Reactions - React to messages with emojis
  • Message Replies - Reply to specific messages
  • Pin to Top - Pin important conversations
  • Block Users - Block unwanted users
  • Online Status - Real-time user online/offline status

1.3 How It Works

  1. Users create or open a chat room with another user
  2. Messages are sent via API and broadcast via Pusher
  3. Recipients receive real-time notifications
  4. Messages are stored in the database for history
  5. Group chat messages are visible to all authenticated users

2.2 Pusher Configuration

Add to your .env file:

PUSHER_APP_ID=your_app_id
PUSHER_APP_KEY=your_app_key
PUSHER_APP_SECRET=your_app_secret
PUSHER_APP_CLUSTER=your_cluster

BROADCAST_DRIVER=pusher

2.3 Database Tables

The package will create the following tables:

  • chat_rooms - Private chat rooms between users
  • chat_messages - All chat messages
  • reacts - Message reactions
  • message_albums - Media attachments
  • message_replays - Reply references
  • pin_to_tops - Pinned conversations
  • block_users - Blocked users
  • group_chat - World chat messages

3. Installation Steps

1 Copy the Package

Copy the Chat folder to your project:

packages/Utd/Chat
2 Update composer.json

Add the package path to your composer.json repositories section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/Chat"
        }
    ]
}
3 Install the Package

Run composer require:

composer require utd/chat
4 Run Setup Commands

Run migrations, seeders, and clear cache (all in one command):

php artisan migrate; php artisan db:seed --class=Utd\Chat\Database\Seeders\ChatDatabaseSeeder; php artisan db:seed --class=PermissionTypeSeeder; php artisan optimize:clear

4. Configuration

4.1 Publish Configuration

Publish the configuration file:

php artisan vendor:publish --tag=chat-config

4.2 Configuration Options

Edit config/chat.php:

return [
    // Group chat message price (diamonds)
    'group_chat_price' => 100,
    
    // Maximum message length
    'max_message_length' => 500,
    
    // Enable/disable features
    'features' => [
        'reactions' => true,
        'replies' => true,
        'media' => true,
    ],
];

4.3 Pusher Events

The package broadcasts the following events:

Event Channel Description
Chat chat-{userId} New message notification
Conversation conversation-{roomId} Message in conversation
OpenChat open-chat-{userId} Chat room opened
GroupChat group-chat World chat message

6. Routes & API

6.1 Private Chat Routes

Method URI Description
GET /api/Chat-room List chat rooms
POST /api/Chat-room Create chat room
GET /api/Chat-room/search-user Find user by UUID
POST /api/Chat-room/accept-request Accept chat request
GET /api/Chat-Message Get messages
POST /api/Chat-Message Send message
POST /api/delete-Chat-Message Delete for all
POST /api/Chat-Message-React Add reaction

6.2 Group Chat Routes

Method URI Description
GET /api/group-chat Get group messages
POST /api/group-chat Send group message

6.3 Admin Routes

URI Description
/admin/group-chat Manage group chat messages
/admin/chat/view Live chat interface
/admin/chat-settings Chat configuration
/admin/setting-group-char Group chat settings

6.4 Verify Routes

php artisan route:list | findstr chat

8. Troubleshooting

8.1 Common Issues

Issue: Route Not Found (404)

Solution: 
php artisan optimize:clear

Issue: Class Not Found Errors

Solution: 
composer dump-autoload
php artisan cache:clear

Issue: Pusher Not Working

Solution:

Check your .env Pusher credentials and ensure:

BROADCAST_DRIVER=pusher

Issue: Messages Not Real-time

Solution:

Ensure queue worker is running:

php artisan queue:work

8.2 Rollback Migrations

php artisan migrate:rollback
