💬 Chat Package
Installation Guide

Requirements

  • PHP 8.1 or higher
  • Laravel 10.x or 11.x
  • MySQL 5.7 or higher
  • Laravel Sanctum installed
  • Pusher or compatible WebSocket service

Installation Steps

1 Copy the Package

Copy the Chat folder to:

packages/Utd/Chat
2 Update composer.json

Add this to your project's composer.json in the "repositories" section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/Chat"
        }
    ]
}
3 Install the Package 
composer require utd/chat
4 Run Setup Commands

Run migrations, seeders, and clear cache:

php artisan migrate; php artisan db:seed --class=Utd\Chat\Database\Seeders\ChatDatabaseSeeder; php artisan db:seed --class=PermissionTypeSeeder; php artisan optimize:clear

Verify Installation

Check if routes are registered:

php artisan route:list | findstr chat
✅ Done! If Chat routes appear, your installation is complete.

API Endpoints

Method Endpoint Description
GET /api/Chat-room Get chat rooms list
POST /api/Chat-room Create new chat room
GET /api/Chat-Message Get messages
POST /api/Chat-Message Send message
GET /api/group-chat Get group chat messages
POST /api/group-chat Send group chat message

Admin Panel

Route Description
/admin/group-chat Manage group chat messages
/admin/chat-settings Chat settings configuration
/admin/setting-group-char Group chat settings
⚠️ Having Issues?
Run: 
php artisan route:list | findstr chat
If no routes appear, contact support.
