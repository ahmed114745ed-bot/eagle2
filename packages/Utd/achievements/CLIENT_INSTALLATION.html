🏆 Achievements Package
Installation Guide

Requirements

  • PHP 8.1 or higher
  • Laravel 10.x or 11.x
  • MySQL 5.7 or higher
  • Laravel-Admin package installed

Installation Steps

1 Copy the Package

Copy the achievements folder to:

packages/Utd/achievements
2 Update composer.json

Add this to your project's composer.json in the "repositories" section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/achievements"
        }
    ]
}
3 Install the Package 
composer require utd/achievements
4 Clear Cache 
php artisan cache:clear
php artisan config:clear
php artisan route:clear
5 Run Migrations 
php artisan migrate
6 Run Database Seeders

Run the Achievement seeders to set up achievement types and levels:

php artisan db:seed --class="Utd\Achievements\Database\Seeders\AchievementDatabaseSeeder"
7 Update Admin Permissions

Run the permissions seeder to add Achievement permissions:

php artisan db:seed --class=PermissionTypeSeeder

Verify Installation

Open your browser and go to:

https://your-domain.com/admin/achievements
✅ Done! If the page loads, your installation is complete.

Configuration (Optional)

Publish the configuration file:

php artisan vendor:publish --tag=achievements-config

Then edit config/achievements.php to customize settings.

⚠️ Having Issues?
Run: 
php artisan route:list | grep achievement
If no routes appear, contact support.
