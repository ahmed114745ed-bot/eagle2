1. Requirements

1.1 Backend Requirements

Requirement Minimum Version Status
PHP 8.1 or higher ✓
Laravel Framework 10.x or 11.x ✓
Laravel-Admin Package 1.8+ ✓
MySQL 5.7 or higher ✓

1.2 Required Contracts

The following contracts must exist in your application's app/Contracts/ directory:

  • AchievementContract.php
  • AchievementLevelContract.php
  • UserAchievementContract.php

1.3 Database Tables

The package will create the following tables:

  • achievements - Main achievements table (Recharge, Room, Gift targets)
  • achievement_levels - Achievement level definitions with targets
  • gift_achievements - Gift-based achievement tracking
  • user_achievements - User progress tracking per achievement
  • user_achievement_levels - User earned achievement levels/medals

2. Installation Steps

1 Copy the Package

Copy the achievements folder to your project:

packages/Utd/achievements
2 Update composer.json

Add the package path to your composer.json repositories section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/achievements"
        }
    ]
}
3 Install the Package

Run composer require:

composer require utd/achievements
4 Run Migrations 
php artisan migrate
5 Run Database Seeders

Run the Achievement seeders to set up achievement types and levels:

php artisan db:seed --class="Utd\Achievements\Database\Seeders\AchievementDatabaseSeeder"
6 Update Admin Permissions

Run the permissions seeder to add Achievement permissions:

php artisan db:seed --class=PermissionTypeSeeder
7 Clear Cache 
php artisan cache:clear
php artisan config:clear
php artisan route:clear
php artisan view:clear

3. Configuration

3.1 Publish Configuration

Publish the configuration file:

php artisan vendor:publish --tag=achievements-config

3.2 Configuration File

After publishing, you can edit the configuration in config/achievements.php:

<?php

return [
    'routes' => [
        'api_enabled' => true,
        'web_enabled' => true,
        'utd_enabled' => true,
    ],
];

3.3 Achievement Types

The package supports three achievement types:

Type Description Tracking Method
RECHARGE_TARGET User recharge/charging achievements Total coins charged
ROOM_TARGET Room activity achievements Room coins earned
GIFT_TARGET Gift-based achievements Gifts received value

4. Database Setup

4.1 Migrations

The package includes the following migrations:

  • create_achievements_table - Main achievements table
  • create_achievement_levels_table - Level definitions
  • create_gift_achievements_table - Gift achievement relations
  • create_user_achievements_table - User progress tracking
  • create_user_achievement_levels_table - User earned medals

4.2 Entity Relationships

Achievement
├── hasMany: AchievementLevel
└── hasMany: UserAchievement

AchievementLevel
├── belongsTo: Achievement
└── hasMany: UserAchievementLevel

UserAchievement
├── belongsTo: User
├── belongsTo: Achievement
└── belongsTo: GiftAchievement (optional)

UserAchievementLevel
├── belongsTo: User
├── belongsTo: AchievementLevel
└── belongsTo: GiftAchievement (optional)

7. Troubleshooting

7.1 Common Issues

Issue: Class Not Found Error

Solution: 
composer dump-autoload
php artisan cache:clear
php artisan config:clear

Issue: Route Not Defined Error

Solution:

Clear route cache and verify routes are registered:

php artisan route:clear
php artisan route:list | findstr achievement

Issue: Contract Not Found

Solution:

Ensure the following contracts exist in app/Contracts/:

  • AchievementContract.php
  • AchievementLevelContract.php
  • UserAchievementContract.php

Issue: Null Service When Package Not Installed

Solution:

Ensure FeatureServiceProvider binds null services when package is absent:

if (!$this->app->bound(UserAchievementContract::class)) {
    $this->app->singleton(UserAchievementContract::class, NullUserAchievementService::class);
}

7.2 Log Files

Check Laravel logs for detailed error information:

storage/logs/laravel.log
