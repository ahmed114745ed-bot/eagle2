🔄 SwitchAccount Package
Installation Guide

Requirements

  • PHP 8.1 or higher
  • Laravel 10.x or 11.x
  • MySQL 5.7 or higher
ℹ️ Dependencies:
The SwitchAccount package has no required dependencies on other Utd packages.

Installation Steps

1 Copy the Package

Copy the SwitchAccount folder to:

packages/Utd/SwitchAccount
2 Update composer.json

Add this to your project's composer.json in the "repositories" section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/SwitchAccount"
        }
    ]
}

And add to the "require" section:

"utd/switch-account": "*"
3 Install the Package 
composer require utd/switch-account
4 Run Setup Commands

Run migrations, seeders, and clear cache:

php artisan migrate
php artisan db:seed --class="Utd\SwitchAccount\Database\Seeders\SwitchAccountDatabaseSeeder"
php artisan db:seed --class=PermissionTypeSeeder
php artisan optimize:clear

Verify Installation

Test the routes:

php artisan route:list | findstr switch-account
php artisan route:list | findstr user-devices

Open your browser and go to:

https://your-domain.com/admin/user-devices-histories
✅ Done! If the routes appear and the admin page loads, your installation is complete.

API Endpoints

Method URI Description
POST /api/add-account Add/link a new account
POST /api/switch-account Switch to a linked account
GET /api/my-accounts Get all linked accounts
⚠️ Having Issues?
Ensure cache is cleared and routes are registered: 
php artisan optimize:clear
php artisan route:list | findstr account
