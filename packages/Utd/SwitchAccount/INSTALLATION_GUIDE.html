2. Installation Steps

1 Copy the Package

Copy the SwitchAccount folder to your project:

packages/Utd/SwitchAccount
2 Update composer.json

Add the package path to your composer.json repositories section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/SwitchAccount"
        }
    ],
    "require": {
        "utd/switch-account": "*"
    }
}
3 Install the Package

Run composer require:

composer require utd/switch-account
4 Run Setup Commands

Run migrations, seeders, and clear cache:

php artisan migrate
php artisan db:seed --class="Utd\SwitchAccount\Database\Seeders\SwitchAccountDatabaseSeeder"
php artisan db:seed --class=PermissionTypeSeeder
php artisan optimize:clear

3. Configuration

3.1 Publish Configuration

Publish the configuration file:

php artisan vendor:publish --tag=config

3.2 Configuration Options

The published config file config/switchaccount.php contains:

return [
    'name' => 'SwitchAccount',
];

5. Routes & Middleware

5.1 Available API Routes

API Routes (Authenticated)

Method URI Description
POST /api/add-account Add/link a new account to current user
POST /api/switch-account Switch to a linked account
GET /api/my-accounts Get all linked accounts for current user

Admin Web Routes

Method URI Description
GET /admin/user-devices-histories List all user device histories
GET /admin/user-devices-histories/{id} View device history details
DELETE /admin/user-devices-histories/{id} Delete device history record

5.2 Middleware

API routes are protected by:

  • auth:sanctum - Authentication required
  • checkLatestToken - Token validation
  • generalBan - Ban check

Admin routes are protected by:

  • web - Web middleware group
  • admin - Admin authentication
  • adminIp - Admin IP restriction
  • multiLanguage - Multi-language support

5.3 Verify Routes

php artisan route:list | findstr switch-account
php artisan route:list | findstr user-devices

6. Contracts & Dependencies

6.1 PackageHelper Integration

The SwitchAccount package is registered in App\Support\PackageHelper:

// In PackageHelper::$packages
'switchAccount' => \Utd\SwitchAccount\Entities\UserAccount::class,

6.2 Checking Package Availability

You can check if the SwitchAccount package is installed before using it:

use App\Support\PackageHelper;

if (PackageHelper::isInstalled('switchAccount')) {
    // SwitchAccount package is available
    $entity = PackageHelper::getEntity('switchAccount');
}

6.3 Service Provider

The SwitchAccountServiceProvider auto-registers via Laravel package discovery. It loads:

  • Routes (API + Web)
  • Migrations
  • Views
  • Configuration
  • Translations

Using cURL or Postman:

curl -X GET "https://your-domain.com/api/my-accounts" \
  -H "Accept: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN"

# Test Add Account
curl -X POST "https://your-domain.com/api/add-account" \
  -H "Accept: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"phone": "1234567890", "password": "secret"}'

# Test Switch Account
curl -X POST "https://your-domain.com/api/switch-account" \
  -H "Accept: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \

8. Troubleshooting

8.1 Common Issues

Issue: Class Not Found Error

Solution: 
composer dump-autoload
php artisan cache:clear

Issue: Views Not Found

Solution: 
php artisan view:clear
php artisan config:clear
php artisan package:discover

Issue: Service Provider Not Registered

Solution: 
php artisan config:clear
php artisan package:discover

Issue: Routes Not Found (404)

Solution: 
php artisan route:clear
php artisan optimize:clear

8.2 Rollback Migrations

To rollback SwitchAccount migrations:

php artisan migrate:rollback --path=packages/Utd/SwitchAccount/Database/Migrations

8.3 Log Files

Check Laravel logs for detailed error information:
