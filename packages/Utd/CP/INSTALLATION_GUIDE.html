1. Overview

1.1 What is CP?

CP (Couple) is a feature that allows users to establish romantic partnerships within the application. Users can request CP relationships, level up together by exchanging gifts, and compete in weekly rankings.

1.2 Key Features

  • CP Relations - Multiple relationship types (lovely, friends, solution, etc.)
  • CP Requests - Send and respond to CP requests
  • CP Levels - Level up your relationship by exchanging gifts
  • Level Rewards - Earn rewards when reaching new levels (coins, VIP, wares, achievements)
  • Weekly Rankings - Compete with other couples for weekly prizes
  • CP Profile - View and display your CP relationship

1.3 How It Works

  1. User sends a CP request to another user with a chosen relation type
  2. Target user accepts/rejects the request
  3. Once accepted, CP is established
  4. Users exchange gifts to increase CP experience (diamonds)
  5. CP levels up and both users receive rewards
  6. Weekly top couples win additional prizes

2.3 Database Tables

The package will create the following tables:

  • cp_relations - Relation types (lovely, friends, etc.)
  • cps - Active CP relationships
  • user_relation_avilables - User available relations
  • cp_level_gifts - Rewards for each level
  • cp_level_take_gifts - Track claimed rewards
  • cp_levels - Level definitions
  • weekly_cp_gifts - Weekly competition rewards
  • weekly_cp_winners - Weekly winners history
  • cp_winner_rewards - Winner reward configurations
  • cp_room_histories - CP room activity history

3. Installation Steps

1 Copy the Package

Copy the CP folder to your project:

packages/Utd/CP
2 Update composer.json

Add the package path to your composer.json repositories section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/CP"
        }
    ]
}
3 Install the Package

Run composer require:

composer require utd/cp
4 Run Setup Commands

Run migrations, seeders, and clear cache (all in one command):

php artisan migrate; php artisan db:seed --class=Utd\CP\Database\Seeders\CPDatabaseSeeder; php artisan db:seed --class=PermissionTypeSeeder; php artisan optimize:clear

4. Configuration

4.1 Publish Configuration

Publish the configuration file:

php artisan vendor:publish --tag=cp-config

4.2 Contract Binding

The package automatically binds the following contract:

App\Contracts\CpServiceContract
→ Utd\CP\Services\CpService

If the package is not installed, a null implementation is used:

App\Contracts\CpServiceContract
→ App\Services\Null\NullCpService

4.3 Scheduled Commands

Add to your app/Console/Kernel.php:

$schedule->command('weekly-cp-winner')->weeklyOn(1, '00:00');

6. Routes & API

6.1 CP Routes

Method URI Description
GET /api/cp-relations Get available relation types
POST /api/make-cp-request Send CP request
GET /api/get-cp-request Get pending requests
POST /api/respond-request Accept/reject request
GET /api/cp-ranking Get CP rankings
GET /api/cp-list Get user's CP list
POST /api/buy-sets Extend CP card
GET /api/cp-profile Get CP profile
GET /api/cp-levels-gifts Get level rewards

6.2 Weekly CP Routes

Method URI Description
GET /api/weekly-cp/pervious-Winners Previous winners
GET /api/weekly-cp/details Weekly details
GET /api/weekly-cp/top-users Top users
GET /api/weekly-cp/user_details User details

8. Troubleshooting

8.1 Common Issues

Issue: Route Not Found (404)

Solution: 
php artisan optimize:clear

Issue: Class Not Found Errors

Solution: 
composer dump-autoload
php artisan cache:clear

Issue: Contract Binding Error

Solution:

Ensure the contract exists in app/Contracts:

App\Contracts\CpServiceContract

And the null service exists:

App\Services\Null\NullCpService

8.2 Rollback Migrations

php artisan migrate:rollback

8.3 Log Files
