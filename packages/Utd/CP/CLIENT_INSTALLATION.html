💕 CP Package
Installation Guide

Requirements

  • PHP 8.1 or higher
  • Laravel 10.x or 11.x
  • MySQL 5.7 or higher
  • Laravel Sanctum installed

Installation Steps

1 Copy the Package

Copy the CP folder to:

packages/Utd/CP
2 Update composer.json

Add this to your project's composer.json in the "repositories" section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/CP"
        }
    ]
}
3 Install the Package 
composer require utd/cp
4 Run Setup Commands

Run migrations, seeders, and clear cache:

php artisan migrate; php artisan db:seed --class=Utd\CP\Database\Seeders\CPDatabaseSeeder; php artisan db:seed --class=PermissionTypeSeeder; php artisan optimize:clear

Verify Installation

Check if routes are registered:

php artisan route:list | findstr cp
✅ Done! If CP routes appear, your installation is complete.

API Endpoints

Method Endpoint Description
GET /api/cp-relations Get relation types
POST /api/make-cp-request Send CP request
GET /api/get-cp-request Get pending requests
POST /api/respond-request Accept/reject request
GET /api/cp-ranking Get CP rankings
GET /api/cp-profile Get CP profile
GET /api/weekly-cp/details Weekly CP details

Scheduled Commands

Add to your app/Console/Kernel.php:

$schedule->command('weekly-cp-winner')->weeklyOn(1, '00:00');
⚠️ Having Issues?
Run: 
php artisan route:list | findstr cp
If no routes appear, contact support.
