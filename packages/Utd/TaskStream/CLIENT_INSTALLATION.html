🎮 TaskStream Package
Installation Guide

Requirements

  • PHP 8.1 or higher
  • Laravel 10.x or 11.x
  • MySQL 5.7 or higher
  • Laravel Sanctum installed
  • Utd/Room package installed

Installation Steps

1 Copy the Package

Copy the TaskStream folder to:

packages/Utd/TaskStream
2 Update composer.json

Add this to your project's composer.json in the "repositories" section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/TaskStream"
        }
    ]
}
3 Install the Package 
composer require utd/task-stream
4 Run Migrations 
php artisan migrate; php artisan optimize:clear

Verify Installation

Check if routes are registered:

php artisan route:list | findstr task-stream
✅ Done! If task-stream routes appear, your installation is complete.

API Endpoints

Task Stream

Method Endpoint Description
GET /api/v1/task-stream Get task stream list
POST /api/v1/task-stream/create Create task stream session
POST /api/v1/task-stream/join Join a task stream
POST /api/v1/task-stream/host-leave Host leaves stream
POST /api/v1/task-stream/send-invitation Send invitation
POST /api/v1/task-stream/respond-invitation Accept/reject invitation

PK Battles

Method Endpoint Description
POST /api/v1/pk/start Start PK battle
POST /api/v1/pk/close End PK battle

Friends

Method Endpoint Description
GET /api/v1/friends/online Get online friends

Database Tables

Table Description
task_streams Main task stream sessions
task_stream_rooms Linked rooms in a stream
task_stream_invitations Invitations between hosts
pk_sessions PK battle sessions

Uninstall

php artisan migrate:rollback --path=packages/Utd/TaskStream/Database/migrations
⚠️ Having Issues?
Make sure Utd/Room package is installed first.
Run: 
php artisan route:list | findstr task-stream
If no routes appear, contact support.
