1. Overview

1.1 What is TaskStream?

TaskStream is a collaborative streaming feature that enables rooms to connect and compete with each other. It powers the PK (Player Kill) battle system where hosts from different rooms compete for gifts and engagement.

1.2 Key Features

  • Room Connections - Link multiple rooms together for collaborative streaming
  • PK Battles - Real-time competition between room hosts with scoring
  • Invitation System - Send and respond to stream invitations
  • Remote Streaming - Support for remote mix streams
  • Win Streak Tracking - Track consecutive PK wins for users
  • Team-based Scoring - Two-team competition with automatic winner determination

1.3 How It Works

  1. Host creates a task stream session in their room
  2. Host sends invitation to another room's host
  3. Invited host accepts/rejects the invitation
  4. Once connected, a PK session can be started
  5. Gifts sent during PK contribute to team scores
  6. Session ends with winner determination based on scores

2.3 Database Tables

The package will create the following tables:

  • task_streams - Main task stream sessions
  • task_stream_rooms - Linked rooms in a task stream
  • task_stream_invitations - Invitations between hosts
  • pk_sessions - PK battle sessions with scoring

The package also adds a win_streak column to the users table.

3. Installation Steps

1 Copy the Package

Copy the TaskStream folder to your project:

packages/Utd/TaskStream
2 Update composer.json

Add the package path to your composer.json repositories section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/TaskStream"
        }
    ]
}
3 Install the Package

Run composer require:

composer require utd/task-stream
4 Run Migrations

Run migrations to create database tables:

php artisan migrate
5 Clear Cache

Clear the application cache:

php artisan optimize:clear
Note

Ensure the Utd/Room package is installed before installing TaskStream, as it is a required dependency.

4. Configuration

4.1 Publish Configuration

Publish the configuration file:

php artisan vendor:publish --tag=task-stream-config

4.2 Configuration Options

The package uses minimal configuration. Most settings are managed through the application.

4.3 Dependency Injection

The package registers TaskStreamServiceContract which can be injected into your services:

use App\Contracts\TaskStreamServiceContract;

class YourService
{
    public function __construct(
        protected TaskStreamServiceContract $taskStreamService
    ) {}
}
Fallback Behavior

If the TaskStream package is not installed, the application will use NullTaskStreamService as a fallback, returning empty results instead of throwing errors.

5. Database Tables Reference

5.1 task_streams (Main Sessions)

Column Type Description
id bigint Primary key
room_id unsignedInteger Reference to rooms table
mix_id string (nullable) External mix stream identifier
is_remote boolean Whether stream is remote
created_at timestamp Creation timestamp
updated_at timestamp Last update timestamp

5.2 task_stream_rooms (Linked Rooms)

Column Type Description
id bigint Primary key
task_stream_id foreignId Reference to task_streams
room_id unsignedInteger Reference to rooms table
created_at timestamp Creation timestamp
updated_at timestamp Last update timestamp

5.3 task_stream_invitations

Column Type Description
id bigint Primary key
task_stream_id foreignId Reference to task_streams
inviter_user_id foreignId User who sent invitation
invitee_user_id foreignId User who received invitation
status enum pending, accepted, rejected
created_at timestamp Creation timestamp
updated_at timestamp Last update timestamp

5.4 pk_sessions (PK Battles)

Column Type Description
id bigint Primary key
task_stream_id foreignId Reference to task_streams
team_1 string Team 1 members (comma-separated IDs)
team_2 string Team 2 members (comma-separated IDs)
status boolean Active status (0=ended, 1=active)
winner tinyInteger (nullable) Winning team (1 or 2)
team_1_score double (nullable) Team 1 total score
team_2_score double (nullable) Team 2 total score
ends_at datetime Scheduled end time
created_at timestamp Creation timestamp
updated_at timestamp Last update timestamp

6. Routes & API

6.1 Task Stream Routes

Base URL: /api/v1/task-stream

Middleware: auth:sanctum, checkLatestToken, generalBan, localization, update.last.seen

Method Endpoint Description
GET / Get task stream index/list
POST /create Create a new task stream session
POST /join Join an existing task stream
POST /host-leave Host leaves the task stream
POST /send-invitation Send invitation to another host
POST /respond-invitation Accept or reject an invitation

6.2 Friends Routes

Base URL: /api/v1/friends

Method Endpoint Description
GET /online Get list of online friends available for invitation

6.3 PK Routes

Base URL: /api/v1/pk

Additional Middleware: pk.live

Method Endpoint Description
POST /start Start a PK battle session
POST /close Close/end a PK battle session

Run the following commands to verify the installation:

composer show utd/task-stream

Check Routes

Check Tables

php artisan tinker

7.2 Test API Endpoints

Test the task stream index endpoint (requires authentication):

curl -X GET "https://your-domain.com/api/v1/task-stream" \
  -H "Authorization: Bearer YOUR_TOKEN"
Success! If all checks pass, the TaskStream package is properly installed and configured.

8. Troubleshooting

8.1 Common Issues

Package Not Found

Error: Package utd/task-stream not found

Ensure the package path is correctly added to composer.json repositories and run composer update.

Migration Errors

Error: Foreign key constraint fails

Ensure the Utd/Room package is installed and rooms table exists before running TaskStream migrations.

Route Not Found

Error: 404 on task-stream routes

Clear route cache: php artisan route:clear and verify the service provider is registered.

8.2 Useful Commands

# Clear all caches
php artisan optimize:clear

# Re-discover packages
composer dump-autoload

# Check service provider registration
php artisan package:discover

# Fresh migration (development only)
php artisan migrate:fresh --seed
