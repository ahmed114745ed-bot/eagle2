2. Installation Steps

1 Copy the Package

Copy the HostLevel folder to your project:

packages/Utd/HostLevel
2 Update composer.json

Add the package path to your composer.json repositories section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/HostLevel"
        }
    ],
    "require": {
        "utd/host-level": "*"
    }
}
3 Install the Package

Run composer require:

composer require utd/host-level
4 Run Setup Commands

Run migrations and clear cache (all in one command):

php artisan migrate; php artisan db:seed --class=PermissionTypeSeeder; php artisan optimize:clear

3. Configuration

3.1 Publish Configuration

Publish the configuration file:

php artisan vendor:publish --tag=config

3.2 Configuration Options

The published config file config/hostlevel.php contains:

return [
    'name' => 'HostLevel',
];

3.3 Admin Settings

The host level schedule type (daily/weekly/monthly) can be configured from the admin panel at:

https://your-domain.com/admin/host-level-settings

5. Routes & Middleware

5.1 Available API Routes

The package registers the following routes:

API Routes (Authenticated)

Method URI Description
GET /api/host-level Get all host levels with user progress
POST /api/host-level/pick Pick/claim a host level reward

Admin Web Routes

Method URI Description
GET /admin/host-levels List all host levels
GET|POST /admin/host-levels/create Create new host level
GET|PUT /admin/host-levels/{id}/edit Edit host level
DELETE /admin/host-levels/{id} Delete host level
GET /admin/host-level-reward/{id} List rewards for a level
GET|POST /admin/host-level-settings Host level settings page

5.2 Middleware

Routes are protected by:

  • api - API middleware group
  • auth:sanctum - Authentication required (API)
  • admin - Admin authentication (Web)

5.3 Verify Routes

php artisan route:list | findstr host-level

6. Contracts & Dependencies

6.1 PackageHelper Integration

The HostLevel package is registered in App\Support\PackageHelper for safe relation loading:

// In PackageHelper::$packages
'hostLevel' => \Utd\HostLevel\Entities\HostLevel::class,

6.2 Safe Relation Loading

Relations in User model use PackageHelper::checkRelation() to gracefully handle missing package:

// In User model
public function hostLevelWinner()
{
    return PackageHelper::checkRelation($this, 'hostLevel', 'hasOne') ??
        $this->hasOne(HostLevelWinner::class, 'user_id', 'id');
}

6.3 Checking Package Availability

You can check if the HostLevel package is installed before using it:

use App\Support\PackageHelper;

if (PackageHelper::isInstalled('hostLevel')) {
    // HostLevel package is available
    $entity = PackageHelper::getEntity('hostLevel');
}

6.4 Service Provider

The HostLevelServiceProvider auto-registers via Laravel package discovery. It loads:

  • Routes (API + Web)
  • Migrations
  • Views
  • Configuration

8. Troubleshooting

8.1 Common Issues

Issue: Class Not Found Error

Solution: 
composer dump-autoload
php artisan cache:clear

Issue: Views Not Found

Solution: 
php artisan view:clear
php artisan config:clear
php artisan package:discover

Issue: Service Provider Not Registered

Solution:

Check that HostLevelServiceProvider is registered:

php artisan config:clear
php artisan package:discover

Issue: Routes Not Found (404)

Solution: 
php artisan route:clear
php artisan optimize:clear

8.2 Rollback Migrations

To rollback HostLevel migrations:

# Rollback HostLevel migrations
php artisan migrate:rollback --path=packages/Utd/HostLevel/database/migrations

9.3 Admin - Manage Host Levels

Host levels are managed through the admin web panel:

  • Create/Edit/Delete levels at /admin/host-levels
  • Manage rewards per level at /admin/host-level-reward/{id}
  • Configure schedule settings at /admin/host-level-settings
