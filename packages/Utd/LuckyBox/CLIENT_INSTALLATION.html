🎁 LuckyBox Package
Installation Guide

Requirements

  • PHP 8.1 or higher
  • Laravel 10.x or 11.x
  • MySQL 5.7 or higher
  • Laravel Sanctum installed

Installation Steps

1 Copy the Package

Copy the LuckyBox folder to:

packages/Utd/LuckyBox
2 Update composer.json

Add this to your project's composer.json in the "repositories" section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/LuckyBox"
        }
    ]
}
3 Install the Package 
composer require utd/luckybox
4 Run Setup Commands

Run migrations, seeders, and clear cache:

php artisan migrate; php artisan db:seed --class=Utd\LuckyBox\Database\Seeders\LuckyBoxDatabaseSeeder; php artisan db:seed --class=PermissionTypeSeeder; php artisan optimize:clear

Verify Installation

Check if routes are registered:

php artisan route:list | findstr box
✅ Done! If box routes appear, your installation is complete.

API Endpoints

Method Endpoint Description
GET /api/box/list Get available boxes
POST /api/box/send Send a box to room
POST /api/box/pickup Pick up a box

Database Tables

Table Description
boxs Box configurations (normal/super)
box_uses Active box instances in rooms
user_box_gifts User rewards from boxes
pick_box_lists Users waiting for super box
user_lucky_gifts Lucky gift rewards

Uninstall

php artisan migrate:rollback --path=packages/Utd/LuckyBox/Database/migrations
⚠️ Having Issues?
Run: 
php artisan route:list | findstr box
If no routes appear, contact support.
