1. Overview

1.1 What is LuckyBox?

LuckyBox is a gamification feature that allows users to send coin-filled boxes in rooms. Other users can pick up these boxes to win coins, creating an engaging interactive experience.

1.2 Key Features

  • Normal Boxes - Standard boxes with configurable coin amounts and user limits
  • Super Boxes - Special boxes with higher rewards
  • Room Integration - Boxes appear in real-time in rooms
  • Coin Distribution - Automatic coin distribution to box pickers
  • Box Duration - Configurable time limits for boxes
  • Lucky Gifts - Additional gift rewards system

1.3 How It Works

  1. User creates a box with specified coins and user limit
  2. Box appears in the room with a countdown timer
  3. Other users in the room can pick up the box
  4. Coins are distributed to users who picked up the box
  5. Remaining coins return to the box creator if time expires

2.3 Database Tables

The package will create the following tables:

  • boxs - Box configurations (normal/super types)
  • box_uses - Active box instances in rooms
  • user_box_gifts - User rewards from picking boxes
  • pick_box_lists - Queue for super box distribution
  • user_lucky_gifts - Lucky gift rewards history

3. Installation Steps

1 Copy the Package

Copy the LuckyBox folder to your project:

packages/Utd/LuckyBox
2 Update composer.json

Add the package path to your composer.json repositories section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/LuckyBox"
        }
    ]
}
3 Install the Package

Run composer require:

composer require utd/lucky-box
4 Run Setup Commands

Run migrations, seeders, and clear cache (all in one command):

php artisan migrate; php artisan db:seed --class=Utd\LuckyBox\Database\Seeders\LuckyBoxDatabaseSeeder; php artisan db:seed --class=PermissionTypeSeeder; php artisan optimize:clear

4. Configuration

4.1 Publish Configuration

Publish the configuration file:

php artisan vendor:publish --tag=luckybox-config

4.2 Configuration Options

Config Key Description Default
app_wallet_lucky_box App wallet for box fees -
normal_box_duration Duration for normal boxes (minutes) 1
lucky_box_percentage Platform fee percentage 0

4.3 Scheduled Commands

Add to your app/Console/Kernel.php:

$schedule->job(new \Utd\LuckyBox\Jobs\NormalLuckyBoxJob)->everyMinute();

5. Database Tables Reference

5.1 boxs (Box Templates)

Column Type Description
id bigint Primary key
type tinyint 0 = normal, 1 = super
coins decimal Coin amount
users int Max users who can pick
duration int Duration in minutes
image string Box image path
has_label boolean Show label on box

5.2 box_uses (Active Boxes)

Column Type Description
id bigint Primary key
box_id bigint Reference to boxs table
user_id bigint User who sent the box
room_id bigint Room where box is active
coins decimal Total coins in box
end_at timestamp When box expires
used_num int Users who picked up
not_used_num int Remaining slots

6. Routes & API

6.1 Mobile API Routes

Method Endpoint Description
GET /api/box/list Get available box templates
POST /api/box/send Send a box to a room
POST /api/box/pickup Pick up a box
POST /api/box/send_test Test super box sending

6.2 UTD Admin API Routes

Method Endpoint Description
GET /api/utd/boxes List all boxes
POST /api/utd/boxes/create Create a box template
POST /api/utd/boxes/update/{id} Update a box template
POST /api/utd/boxes/delete/{id} Delete a box template
GET /api/utd/thrown-boxes List active boxes in rooms

6.3 Web Admin Routes (Encore)

Route Description
/admin/lucky-boxes Manage box templates
/admin/thrown-boxes View active boxes

7. Verification

7.1 Check Routes

Verify routes are registered:

php artisan route:list | findstr box

7.2 Check Tables

Verify tables exist in database:

php artisan tinker
>>> Schema::hasTable('boxs')
>>> Schema::hasTable('box_uses')

7.3 Test API

Test the box list endpoint:

curl -X GET http://your-app.test/api/box/list \
  -H "Authorization: Bearer YOUR_TOKEN"
✅ Installation Complete!

If all checks pass, your LuckyBox package is ready to use.

8. Troubleshooting

8.1 Common Issues

Routes Not Found

⚠️ Problem

Box routes are not appearing in route:list

Solution

Clear route cache and re-register:

php artisan route:clear
php artisan optimize:clear

Migration Errors

⚠️ Problem

Tables already exist or foreign key errors

Solution

Rollback and re-run migrations:

php artisan migrate:rollback --path=packages/Utd/LuckyBox/Database/migrations
php artisan migrate --path=packages/Utd/LuckyBox/Database/migrations

Service Provider Not Loaded

⚠️ Problem

Package features not working

Solution

Check if package is discovered:

php artisan package:discover

8.2 Uninstall Package

To completely remove the package:

# Rollback migrations
php artisan migrate:rollback --path=packages/Utd/LuckyBox/Database/migrations

# Remove from composer
composer remove utd/lucky-box

# Clear cache
php artisan optimize:clear
