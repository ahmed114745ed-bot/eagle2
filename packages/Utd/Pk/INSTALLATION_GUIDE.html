2. Installation Steps

1 Ensure Room Package is Installed

Verify that the Room package is already installed:

composer show utd/room

If not installed, install Room first before proceeding.

2 Copy the Package

Copy the Pk folder to your project:

packages/Utd/Pk
3 Update composer.json

Add the package path to your composer.json repositories section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/Pk"
        }
    ],
    "require": {
        "utd/pk": "*"
    }
}
4 Install the Package

Run composer require:

composer require utd/pk
5 Run Setup Commands

Run migrations, seeders, and clear cache (all in one command):

php artisan migrate; php artisan db:seed --class=PermissionTypeSeeder; php artisan db:seed --class="Utd\Pk\Database\Seeders\PkDatabaseSeeder"; php artisan optimize:clear

3. Configuration

3.1 Environment Variables

Add these to your .env file:

# PK Package Configuration
PK_ENABLED=true

# PK Battle Settings
PK_DEFAULT_DURATION=300
PK_MIN_PARTICIPANTS=2
PK_MAX_ROUNDS=5

# Scoring Settings
PK_GIFT_MULTIPLIER=1.0
PK_WIN_BONUS=100

# Cache Settings
PK_CACHE_TTL=60

3.2 Publish Configuration

Publish the configuration file:

php artisan vendor:publish --tag=pk-config

3.3 Configuration Options

The published config file config/pk.php contains:

return [
    'enabled' => env('PK_ENABLED', true),
    'default_duration' => env('PK_DEFAULT_DURATION', 300),
    'min_participants' => env('PK_MIN_PARTICIPANTS', 2),
    'max_rounds' => env('PK_MAX_ROUNDS', 5),
    'gift_multiplier' => env('PK_GIFT_MULTIPLIER', 1.0),
    'win_bonus' => env('PK_WIN_BONUS', 100),
    'cache_ttl' => env('PK_CACHE_TTL', 60),
];

4. Database Tables

4.1 PKs Table Structure

pks

Column Type Description
id bigint Primary key
room_id bigint Room reference (FK to rooms)
status tinyint PK status (0=ended, 1=active)
t1_score decimal Team 1 score
t2_score decimal Team 2 score
mics json Microphone positions for teams
start_at timestamp PK start time
end_at timestamp PK end time
created_at timestamp Record creation time
updated_at timestamp Record update time

4.2 Relationships

  • Pk belongs to Room
  • Room has many Pk (history)
  • Room has one active Pk (lastPk)

The package registers the following routes:

PK Management Routes (Authenticated)

Method URI Description

POST /api/Utd/pk/without-zego/hide Hide PK without Zego

Public Routes

Method URI Description
GET /api/Utd/pk/room/{id}/pks Get all PKs for a room

5.2 Middleware

Routes are protected by:

  • api - API middleware group
  • auth:sanctum - Authentication required
  • appFeatureEnable:pk - PK feature must be enabled

6. Contracts & Dependencies

6.1 Contract Pattern

The PK package uses the contract pattern for loose coupling:

PkRepositoryContract

Location: App\Contracts\PkRepositoryContract

interface PkRepositoryContract
{
    public function getActiveByRoom($roomId);
    public function getByRoom($roomId);
    public function endPk($pkId);
    public function getPk($roomId);
    public function findById($id);
    public function roomPks($userId, $perPage, $page);
    public function create(array $data);
    public function update(array $data, $id);
}

6.2 Service Provider Bindings

The PkServiceProvider binds the contract:

// In PkServiceProvider::register()
$this->app->singleton(
    PkRepositoryContract::class, 
    PkRepository::class
);

6.3 Null Implementation

If the PK package is not installed, FeatureServiceProvider provides a null implementation:

// In FeatureServiceProvider::register()
if (!$this->app->bound(PkRepositoryContract::class)) {
    $this->app->singleton(
        PkRepositoryContract::class,
        NullPkRepository::class
    );
}

6.4 Using the Contract

Inject the contract in your services:

use App\Contracts\PkRepositoryContract;

class YourService
{
    public function __construct(
        private readonly PkRepositoryContract $pkRepository
    ) {}
    
    public function getActivePk($roomId)
    {
        return $this->pkRepository->getActiveByRoom($roomId);
    }
}

8. Troubleshooting

8.1 Common Issues

Issue: Class Not Found Error

Solution: 
composer dump-autoload
php artisan cache:clear

Issue: Room Package Not Found

Solution:

Install the Room package first:

composer require utd/room
php artisan migrate

Issue: Migration Errors (Foreign Key)

Solution:

Ensure rooms table exists before running PK migrations:

php artisan migrate:status
# If rooms table missing, run Room migrations first

Issue: Contract Not Resolving

Solution:

Check that PkServiceProvider is registered:

php artisan config:clear
php artisan package:discover

Issue: Routes Not Found (404)

Solution: 
php artisan route:clear
php artisan optimize:clear

8.2 Rollback Migrations

To rollback PK migrations:

# Rollback PK migrations
php artisan migrate:rollback --path=packages/Utd/Pk/Database/migrations

8.3 Log Files

Check Laravel logs for detailed error information:

storage/logs/laravel.log
