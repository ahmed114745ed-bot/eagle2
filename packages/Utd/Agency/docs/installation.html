📦 Agency Package

حزمة إدارة الوكالات لتطبيقات Laravel

v1.0.0 Laravel 10+

📋 المتطلبات

  • ✓ PHP >= 8.1
  • ✓ Laravel >= 10.x
  • ✓ MySQL >= 5.7 or MariaDB >= 10.3
  • ✓ Composer

🚀 خطوات التثبيت

1
إضافة الحزمة إلى composer.json
أضف مسار الحزمة إلى قسم autoload في ملف composer.json
{
    "autoload": {
        "psr-4": {
            "Utd\\Agency\\": "packages/Utd/Agency/src/"
        }
    }
}
2
تحديث Composer Autoload
قم بتحديث ملفات الـ autoload
composer dump-autoload
3
تسجيل Service Provider
أضف الـ Service Provider في ملف config/app.php
'providers' => [
    // ...
    Utd\Agency\AgencyServiceProvider::class,
],
4
تشغيل أمر التثبيت
قم بتشغيل أمر التثبيت الذي سيقوم بإنشاء الجداول والأعمدة
php artisan agency:install
💡 خيارات إضافية:
--force لإعادة التثبيت حتى لو كانت الحزمة مثبتة
--seed لتشغيل الـ Seeders بعد التثبيت
5
نشر ملفات الإعدادات (اختياري)
يمكنك نشر ملف الإعدادات لتخصيص سلوك الحزمة
php artisan vendor:publish --tag=agency-config

⚡ الأوامر المتاحة

php artisan agency:install
تثبيت الحزمة وإنشاء الجداول والأعمدة المطلوبة
php artisan agency:install --seed
تثبيت الحزمة مع تشغيل الـ Seeders
php artisan agency:install --force
إعادة تثبيت الحزمة (تجاهل التثبيت السابق)
php artisan agency:uninstall
إزالة الحزمة وحذف جميع البيانات
php artisan agency:uninstall --keep-data
إزالة الحزمة مع الاحتفاظ بالبيانات

🗑️ إزالة الحزمة

ℹ️ ملاحظة: إزالة الحزمة بشكل افتراضي لا تحذف البيانات من قاعدة البيانات، فقط تزيل الكود والإعدادات.

خطوات الإزالة الآمنة (بدون حذف البيانات)

1
تشغيل أمر الإزالة
php artisan agency:uninstall
⚠️ تحذير: إذا أردت حذف جميع بيانات الوكالات من قاعدة البيانات، استخدم: 
php artisan agency:uninstall --remove-data
2
إزالة Service Provider
احذف السطر التالي من config/app.php
Utd\Agency\AgencyServiceProvider::class,
3
إزالة Autoload
احذف السطر التالي من composer.json
"Utd\\Agency\\": "packages/Utd/Agency/src/"
4
تحديث Composer
composer dump-autoload

⚙️ الإعدادات

يمكنك تخصيص سلوك الحزمة من خلال ملف config/agency-package.php

return [
    // تفعيل/تعطيل المسارات
    'routes' => [
        'api_enabled' => true,
        'web_enabled' => true,
        'utd_enabled' => true,
    ],

    // النماذج القابلة للتخصيص
    'models' => [
        'user' => \App\Models\User::class,
        'agency' => \Utd\Agency\Models\Agency::class,
    ],
];

🔧 حل المشاكل

Class not found error

تأكد من تشغيل composer dump-autoload بعد إضافة الحزمة

Migration errors

إذا كانت الجداول موجودة مسبقاً، استخدم php artisan agency:install --force

Permission errors

تأكد من صلاحيات الكتابة على مجلدات storage و bootstrap/cache
