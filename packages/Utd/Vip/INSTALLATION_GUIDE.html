Overview

Installation

Step 1: Copy Package

Copy the Vip folder to your packages directory:

packages/Utd/Vip
Step 2: Update composer.json

Add the repository and require the package:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/Vip",
            "options": {
                "symlink": true
            }
        }
    ],
    "require": {
        "utd/vip": "*"
    }
}
Step 3: Install via Composer
composer update utd/vip
Step 4: Run Migrations
php artisan migrate
Step 5: Run Seeders
php artisan db:seed --class=PermissionTypeSeeder; php artisan db:seed --class="Utd\Vip\Database\Seeders\VipDatabaseSeeder"
Step 6: Clear Cache
php artisan optimize:clear
✅ Installation Complete!
The package is now installed and ready to use.

Contracts & Integration

The VIP package exposes contracts for external integration. When the package is not installed, null implementations are automatically used.

Available Contracts

ContractDescription
VipCommonContractMain VIP helper with activation, deactivation methods
OvipRepositoryContractRepository for OVip entities
UserVipRepositoryContractRepository for UserVip entities

Usage Example

use App\Contracts\VipCommonContract;

// Get VIP service (returns null implementation if package not installed)
$vipService = app(VipCommonContract::class);

// Create user VIP
$vipService->createUserVip($userId, $vipId, $days);

// Check if user has active VIP
$hasVip = $vipService->userHasActiveVip($userId);
📘 Note:
Use PackageHelper::isInstalled('vip') to check if the VIP package is installed before showing VIP-related UI elements.

Package Removal

⚠️ Warning: Removing this package will affect VIP functionality. Ensure fallback contracts are properly configured.
Step 1: Remove Package
composer remove utd/vip
Step 2: Rollback Migrations (Optional)
php artisan migrate:reset --path=packages/Utd/Vip/Database/Migrations
Step 3: Remove Repository Entry

Remove the Vip repository entry from composer.json.

Step 4: Delete Package Folder
rm -rf packages/Utd/Vip
Step 5: Clear Cache
php artisan optimize:clear
📘 Note:
After removal, the application will automatically use null implementations for VIP contracts, ensuring no errors occur.
