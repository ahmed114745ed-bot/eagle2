2. Installation Steps

1 Copy the Package

Copy the RankingReward folder to your project:

packages/Utd/RankingReward
2 Update composer.json

Add the package path to your composer.json repositories section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/RankingReward"
        }
    ],
    "require": {
        "utd/ranking-reward": "*"
    }
}
3 Install the Package

Run composer require:

composer require utd/ranking-reward
4 Run Setup Commands

Run migrations and clear cache (all in one command):

php artisan migrate; php artisan db:seed --class=PermissionTypeSeeder; php artisan optimize:clear

3. Configuration

3.1 Publish Configuration

Publish the configuration file:

php artisan vendor:publish --tag=config

3.2 Configuration Options

The published config file config/RankingReward.php contains:

return [

The Ranking Reward schedule type (daily/weekly/monthly) can be configured from the admin panel at:

https://your-domain.com/admin/ranking-reward-settings

5. Routes & Middleware

5.1 Available API Routes

The package registers the following routes:

API Routes (Authenticated)

Method URI Description
GET /api/ranking-reward Get all Ranking Rewards with user progress
POST /api/ranking-reward/pick Pick/claim a Ranking Reward reward

Admin Web Routes

Method URI Description
GET /admin/ranking-rewards List all Ranking Rewards
GET|POST /admin/ranking-rewards/create Create new Ranking Reward
GET|PUT /admin/ranking-rewards/{id}/edit Edit Ranking Reward
DELETE /admin/ranking-rewards/{id} Delete Ranking Reward
GET /admin/ranking-reward-reward/{id} List rewards for a level
GET|POST /admin/ranking-reward-settings Ranking Reward settings page

5.2 Middleware

Routes are protected by:

  • api - API middleware group
  • auth:sanctum - Authentication required (API)
  • admin - Admin authentication (Web)

5.3 Verify Routes

php artisan route:list | findstr ranking-reward

6. Contracts & Dependencies

6.1 PackageHelper Integration

The RankingReward package is registered in App\Support\PackageHelper for safe relation loading:

// In PackageHelper::$packages
'RankingReward' => \Utd\RankingReward\Entities\RankingReward::class,

6.2 Safe Relation Loading

Relations in User model use PackageHelper::checkRelation() to gracefully handle missing package:

// In User model
public function RankingRewardWinner()
{
    return PackageHelper::checkRelation($this, 'RankingReward', 'hasOne') ??
        $this->hasOne(RankingRewardWinner::class, 'user_id', 'id');
}

6.3 Checking Package Availability

You can check if the RankingReward package is installed before using it:

use App\Support\PackageHelper;

if (PackageHelper::isInstalled('RankingReward')) {
    // RankingReward package is available
    $entity = PackageHelper::getEntity('RankingReward');
}

6.4 Service Provider

The RankingRewardServiceProvider auto-registers via Laravel package discovery. It loads:

  • Routes (API + Web)
  • Migrations
  • Views
  • Configuration

8. Troubleshooting

8.1 Common Issues

Issue: Class Not Found Error

Solution: 
composer dump-autoload
php artisan cache:clear

Issue: Views Not Found

Solution: 
php artisan view:clear
php artisan config:clear
php artisan package:discover

Issue: Service Provider Not Registered

Solution:

Check that RankingRewardServiceProvider is registered:

php artisan config:clear
php artisan package:discover

Issue: Routes Not Found (404)

Solution: 
php artisan route:clear
php artisan optimize:clear

To rollback RankingReward migrations:

  • Manage rewards per level at /admin/ranking-reward-reward/{id}
  • Configure schedule settings at /admin/ranking-reward-settings
