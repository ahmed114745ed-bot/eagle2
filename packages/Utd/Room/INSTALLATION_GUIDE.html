2. Installation Steps

1 Copy the Package

Copy the Room folder to your project:

packages/Utd/Room
2 Update composer.json

Add the package path to your composer.json repositories section:

{
    "repositories": [
        {
            "type": "path",
            "url": "packages/Utd/Room"
        }
    ]
}
3 Install the Package

Run composer require:

composer require utd/room
4 Run Setup Commands

Run migrations, seeders, and clear cache (all in one command):

php artisan migrate; php artisan db:seed --class=Utd\Room\Database\Seeders\RoomDatabaseSeeder; php artisan db:seed --class=PermissionTypeSeeder; php artisan optimize:clear

3. Configuration

3.1 Environment Variables

Add these to your .env file:

# Room Package Configuration
ROOM_ENABLED=true

# Microphone Settings
ROOM_MAX_MICROPHONES=8
ROOM_DEFAULT_MIC_QUEUE_SIZE=50

# Room Settings
ROOM_DEFAULT_CAPACITY=100
ROOM_MAX_ADMINS=10
ROOM_VISITOR_TRACKING=true

# PK Battle Settings
ROOM_PK_ENABLED=true
ROOM_PK_DEFAULT_DURATION=300
ROOM_PK_MIN_PARTICIPANTS=2

# Cache Settings
ROOM_CACHE_TTL=3600
ROOM_VISITORS_CACHE_TTL=60

3.2 Publish Configuration

Publish the configuration file (if available):

php artisan vendor:publish --tag=room-config

4. Database Tables Reference

4.1 Main Tables Structure

rooms

Column Type Description
id bigint Primary key
user_id bigint Owner user ID
name string Room name
description text Room description
cover string Cover image path
category_id bigint Category reference
is_private boolean Private room flag
password string Room password (nullable)
status tinyint Room status

room_microphones

Column Type Description
id bigint Primary key
room_id bigint Room reference
user_id bigint User on microphone
position integer Microphone position (1-8)
is_muted boolean Muted status
is_locked boolean Locked status

5. Routes & Middleware

5.1 Available Routes

The package registers the following routes:

API Routes (Mobile App)

Method URI Description
GET /api/Utd/rooms List rooms
GET /api/Utd/rooms/{id} Get room details
POST /api/Utd/rooms Create room
PUT /api/Utd/rooms/{id} Update room
DELETE /api/Utd/rooms/{id} Delete room
POST /api/Utd/rooms/{id}/join Join room
POST /api/Utd/rooms/{id}/leave Leave room

Microphone Routes

Method URI Description
POST /api/Utd/rooms/{id}/mic/request Request microphone
POST /api/Utd/rooms/{id}/mic/leave Leave microphone
POST /api/Utd/rooms/{id}/mic/kick Kick from microphone
POST /api/Utd/rooms/{id}/mic/lock Lock microphone
POST /api/Utd/rooms/{id}/mic/mute Mute microphone

PK Battle Routes

Method URI Description
POST /api/Utd/rooms/{id}/pk/start Start PK battle
POST /api/Utd/rooms/{id}/pk/end End PK battle
GET /api/Utd/rooms/{id}/pk/status Get PK status
POST /api/Utd/rooms/{id}/pk/invite Invite to PK

Admin Panel Routes

Method URI Description
GET /admin/rooms Rooms management
GET /admin/room-categories Categories management
GET /admin/room-backgrounds Backgrounds management
GET /admin/room-frames Frames management
GET /admin/room-themes Themes management

7. Troubleshooting

7.1 Common Issues

Issue: Page Not Found (404)

Solution: 
php artisan optimize:clear

Issue: Migration Errors

Solution:

Check if dependent packages are installed first:

# Ensure these packages are migrated first:
# - Utd/Wallet
# - Utd/Gift

php artisan migrate:status
php artisan migrate

Issue: Foreign Key Constraint Errors

Solution:

Run migrations in the correct order:

  1. Core Laravel migrations
  2. Utd/Wallet package
  3. Utd/Gift package
  4. Utd/Room package

Issue: Class Not Found Errors

Solution: 
composer dump-autoload
php artisan cache:clear

Issue: Admin Menu Not Showing

Solution:

Run the database seeder:

php artisan db:seed --class=Utd\Room\Database\Seeders\RoomDatabaseSeeder

7.2 Rollback Migrations

To rollback room migrations:

# Rollback all room migrations
php artisan migrate:rollback --path=packages/Utd/Room/Database/migrations

# Or rollback specific batch
php artisan migrate:rollback --step=1

7.3 Log Files

Check Laravel logs for detailed error information:

storage/logs/laravel.log

8. API Reference

8.1 List Rooms

GET /api/Utd/rooms

Parameters:
- page (int): Page number
- per_page (int): Items per page (default: 15)
- category_id (int): Filter by category
- search (string): Search by name
- sort (string): Sort by (newest, popular, trending)

Response:
{
    "data": [...],
    "current_page": 1,
    "last_page": 10,
    "per_page": 15,
    "total": 150
}

8.2 Get Room Details

GET /api/Utd/rooms/{id}

Response:
{
    "id": 1,
    "user_id": 123,
    "name": "Cool Room",
    "description": "...",
    "cover": "path/to/cover.jpg",
    "category": {...},
    "visitors_count": 50,
    "microphones": [...],
    "created_at": "2026-02-01T10:00:00Z"
}

8.3 Create Room

POST /api/Utd/rooms

Request Body:
{
    "name": "My Room",
    "description": "Room description",
    "category_id": 1,
    "is_private": false,
    "password": null
}

Response:
{
    "success": true,
    "data": {...},
    "message": "Room created successfully"
}

8.4 Join Room

POST /api/Utd/rooms/{id}/join

Request Body:
{
    "password": "optional_password"
}

Response:
{
    "success": true,
    "data": {
        "room": {...},
        "token": "agora_token_here"
    }
}

8.5 Request Microphone

POST /api/Utd/rooms/{id}/mic/request

Request Body:
{
    "position": 1
}

Response:
{
    "success": true,
    "message": "Microphone request sent"
}

8.6 Start PK Battle

POST /api/Utd/rooms/{id}/pk/start

Request Body:
{
    "opponent_room_id": 456,
    "duration": 300,
    "rounds": 3
}

Response:
{
    "success": true,
    "data": {
        "pk_id": 1,
        "status": "waiting",
        "expires_at": "..."
    }
}
